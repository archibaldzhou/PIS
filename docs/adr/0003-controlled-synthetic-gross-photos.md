# ADR 0003：取材图像先使用私有只读合成对象

状态：T11 合成开发范围采用，2026-10-02。

取材照片需要稳定来源、私有存储、撤权及失败恢复。当前未批准真实患者图像、对象存储服务或图片解析依赖，所以开发附件闭环限定为程序自带的一份合成 PNG。`PhotoStore` 是应用边界，当前 `SyntheticPhotoStore` 只允许完全一致的已知字节，不读取任意路径、URL 或真实照片，不解析不可信图片。未引入生产依赖。

资源 `backend/src/main/resources/grossing-assets/synthetic-v1.png` 为本项目程序生成的 256×160 示意图，656 字节，SHA256 `adaacd24ed0218efbde244a9a0c314cf26b8f27f612146bd9d164971fcb92623`；无患者或外部版权素材，不代表病理影像或可校准测量。应用启动校验其摘要，私有资源不位于静态 web 目录。此唯一源资产可提交；原型包、用户图片、运行截图仍不入库。

PG 只保存关联、对象 key/hash/大小/尺寸与历史。对象预先存在且不可更改，写事务失败只回滚元数据，不产生孤儿对象，不需要模拟异步上传成功。后续通用照片上传必须另行实现隔离暂存、配额、可信解码/转码、原子发布与失败对账，而不能扩大此字节白名单后声称已完成安全上传。

认证、READ/GROSS 与同病例容器校验覆盖附件写入和每次下载。JSON 解析前限制32KiB（包括无 Content-Length 的分块请求），base64解码与摘要验证再限制对象。撤回阻止新下载，保留元数据和历史；已经交付给客户端的数据无法远程收回。浏览器关闭图像、切记录或退出会撤销其内存 Blob URL。取消整条记录也阻止新下载。

所有描述/谱系/附件/事件/审计/回执在既有幂等短事务中写入；读取记录及图像也在授权后锁住申请，防止读到跨修订拼接视图。只读合成对象接口不进行网络 I/O，不占长事务。
