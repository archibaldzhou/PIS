# ADR0024：持久化合成契约 worker，不授予模型执行许可

2026-10-04，用户授权开发。沿用单体 JDBC/PostgreSQL 与本地私有存储，无新依赖、凭据、模型权重、网络服务或 GPU。

T34 `executionAllowed=false` 保持不变。单独 `pis.ai.synthetic-worker-enabled=false`，即使打开也必须 dev/test 且不能 prod。资格表无种子；原提交者必须同时有当前病例、扫描、QC、AI契约、存储及限时任务资格。owner_auth_version 固定；身份变更后不能通过新会话继承旧任务操作权。此阶段没有后台服务身份，只有明确认证会话驱动的 synthetic contract worker；不宣称自动调度或生产推理。

任务+outbox+审计原子提交；DB任务CAS、generation和租约授权完成流转。领取通过数据库互斥锁限制最多2个未过期租约，不通过扩大线程数/隐藏重试伪造容量。30秒租约、120秒截止、3次尝试、5/10/20秒退避是合成开发常量，不是临床SLA。出站记录保存已排队/已领取/已终止状态，进程重启读取持久状态；超时需明确对账，重试需明确人工操作。重放先重查当前权限与依赖，回调唯一ID固定为服务端租约ID，不接受回调URL。

产物只含技术任务ID、代次、绑定digest和非诊断声明，最多4KiB。T28新增独立用途，仅Java域边界可预约，通用原件HTTP预约/读取拒绝该用途。任务消费入口再次检查当前模型/QC/身份/病例，不能通过旧对象ID绕过撤销。

文件与数据库不假设分布式原子性。每代次稳定预约键，attempt记录一次绑定；文件阶段复用T28暂存/hash/finalize。最终接受回调和审计同一事务，失败后保留未接受的不可变文件，原键恢复；旧代次文件不自动清理或复用成新结果。部分/失败文件不会变成成功；对账可转FAILED/超时，再按新代次重试。

无临床文本、概率、热图、诊断或模型二进制输出。实际生成固定合成技术夹具不是AI推理，其完成状态专名 SYNTHETIC_SUCCEEDED。真实模型、训练、临床验证、监管许可、远程worker凭据与生产容量均不在本任务。
