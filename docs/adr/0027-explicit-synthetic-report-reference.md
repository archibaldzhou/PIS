# ADR 0027 — 显式人工合成引用与报告修订

T37，仅开发合成模式，沿用现有 JDBC、事务及幂等机制，无新增依赖。

人工决定属于 report 域，通过 AiResultService 的公开 metadata/reference 契约读取来源。没有直接调用 AI 内部 Repository。reference 只提供授权历史快照及当前依赖失效状态；实际写命令和重放仍用 metadata 检查精确任务、存储产物完整性和当前权限。保留既有任务所有者限制，不隐式扩大医生共享范围。

病例行锁与既有报告/分配事务协调；每病例/结果独立 CAS head。命令内重新验证诊断资格、领取、QC、来源和目标修订。采纳生成原字段及模板完全不变的新草稿修订，再记录精确来源引用；拒绝/暂缓只追加决定。数据库触发器验证来源 hash、目标和采纳修订字段一致性，禁止更新或删除决定。业务记录、草稿、幂等回执及命令审计同事务。

不能将合成输出写成医学诊断，不能自动签署。引用按具体采纳修订查询，后续手工编辑不自动形成新采纳。T38 的广泛失效传播不在此任务；当前失效来源仍立即阻止新命令和重放，历史通过现有授权保留。当前已模拟签署的报告不接受新决定。

前端先核验来源，再明确确认；不确定写结果保留完整原键/原输入。取消等待不等于撤销写操作。卸载、切换和读取取消通过 AbortController 和代次隔离，不能将旧来源恢复到新表单。无临床执行权限、外部模型、真实患者或新增凭据。
