# ADR0023：仅合成AI模型注册与适用契约

2026-10-03，T34开发决定；无临床/监管批准。无新增依赖、模型下载、运行时、密钥或外部服务。

采用已有PostgreSQL/JDBC、T07命令及审计，新增V31。医院/组织范围模型系列有CAS头；每个元数据版本独立UUID，digest是人工声明而非已下载校验的模型文件。模型状态由独立CAS和追加事件维护，只允许DRAFT、VALIDATION_ONLY、DISABLED、RETIRED；退休不可逆。新版本从DRAFT开始，旧版不会因沿用代码或digest继续取得当前适用资格。

`ai_registry_grant`是独立限时合成资格，注册、验证状态管理、适用核对三项独立开关，全部叠加现有workflow范围。没有临床批准或推理执行权限。管理员角色不产生此grant，生产迁移没有账号、资格或模型种子。T35必须重新核验当前依赖，不能把T34回执当任务授权。

T29没有可靠的病理类型/染色/扫描仪软件版本；不从文件名、临床文本或设备代码推断。新增人工合成profile，允许UNKNOWN，追加版本绑定当前扫描和manifest。设备代码仍来自T29，精确原件、身份、QC及对象权限通过T30/T31公开接口重查；校准只来自T32。当前支持契约仅SYN-RGB-PYRAMID-1，需已有真实生成manifest；没有manifest/不支持格式直接拒绝，不伪造适用依据。

配置schema固定SYN-AI-CONFIG-1：maxTiles是未来单个输入批次上限1–16的声明，不是金字塔总瓦片数，也不调度任务。每版本声明一个准确的合成病理/染色/扫描仪/软件组合；PIXEL_ONLY显式不要求物理尺度，SYNTHETIC_XY_MPP_REQUIRED必须有当前合成XY校准。真实批准范围不受支持，只有SYNTHETIC_CONTRACT_ONLY。MISSING证据返回NEEDS_REVIEW；DECLARED_SYNTHETIC只是人工合成引用，不代表独立验证证据，更不代表监管许可。

写事务锁定当前用户、范围、资格；版本和状态遵循系列→状态锁序。扫描判定继承请求锁并锁定模型当前头/状态，判定保存与审计原子提交。旧判定读取与原键重试重新计算并比较完整快照，模型、资料、校准、QC或身份变化即拒绝。历史记录不删除，模型历史提供授权查询；失效判定不通过当前判定接口返回为可用结果。

前端独立扫描入口保留明确病例/扫描身份；全局管理入口不暗中选择病例。写结果未知保留同一键和负载，停止等待不表示服务端撤销；显式放弃重试后重读。当前判定5秒核验一次，单个检查最多10秒且不叠加，任何失败清除当前结果；该显示机制不代替每个服务端消费请求重新授权。
