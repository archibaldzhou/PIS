## 背景与决定

用户规范是新系统评审基线，明确要求保留已有工具和有效决策。本仓库已有 T02–T07 的基础、安全与幂等实现。根级 AGENTS.md 将规范适配为后续开发约束；本次不重构代码、不升级依赖、不改安全链或已执行迁移。规范中未实现的要求是后续门槛，不能以文档存在代替实现或验证。

## 业务与权限决定不变

T05 一申请多病例、编号域及可空字段仍是结构模板/待确认假设；T06 角色仍是模板，管理员无病例默认权限和签发权限；T07 通用执行器不能替代 T08/T09 用例授权与原子写。新业务必须证明跨院/跨患者/撤权竞争、状态/版本冲突、重复请求和审计失败回滚，不改旧迁移填补新流程。

开发/CI 的 PG 超级用户不是生产最小权限；AuditPrivilegesTest 验证的是合成临时角色，不是已部署 runtime 账号。真实患者、诊断签发、WSI、临床 AI、部署均未获此 ADR 授权。
