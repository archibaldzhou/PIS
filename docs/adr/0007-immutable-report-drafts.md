# ADR 0007：不可变模板与人工报告草稿

2026-10-03，开发范围已采纳。依据[T17 PRD](../prd/development-report-drafts-v1.md)及授权UI-020；不构成临床批准。

报告域通过DiagnosisService.reportContext公开边界复用当前有效资格、组织/病例READ、ACTIVE持有人和质量门禁，不复制资格规则，不依赖UI隐藏。转交撤销旧医生访问；受让人必须领取。读事务在申请根共享锁后重新授权；写事务由T07独占管理，在根更新锁后再次验证身份、分配版本及QC，避免检查与写入脱节。

模板(code,version)与schemaCode不可变；闭合的合成模式有明确字符串、整数、布尔类型，不隐式转换、不生成诊断文本。改变规则必须新增schemaCode，不能改变旧模板的验证语义。迁移不种模板，测试夹具提供两个明确合成版本；当前目录返回最多100个模板，超过时应增加分页设计，不静默替代旧模板。

草稿头通过(case,version,revision)复合外键绑定完整不可变快照，每次CAS只增加一个版本。模板切换保存新修订，历史保留旧模板和字段。修订、头、T07审计和幂等回执同事务，审计失败回滚。审计不复制报告正文；原因和人工输入仅在授权修订中追溯。重放也验证当前医生权限，历史成功回执不代表当前QC仍通过。

前端模板切换显式清空并确认，病例切换有脏提示，旧响应按代次丢弃。未知保存结果冻结原输入和原键以确认；确定冲突保留输入供人工核对，不能自动覆盖。无自动保存、AI、复核、签署或发送接口。

代价：仅合成模式，模板管理与医院审批未实现；系统浏览器UI/SQL探针不能替代完整Spring、真实E2E和正式CI，验证边界见[交付记录](../api/t17-development-status.md)。
