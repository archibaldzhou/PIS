# ADR 0018：私有合成原件与可恢复完成协议

2026-10-03，T28开发采纳；不代表生产存储或WSI验收。

使用JDK21文件API，不新增依赖或SDK。JDK沿用Temurin/OpenJDK GPLv2 with Classpath Exception；无外部字体、解析器、网络抓取或对象存储服务。S3StorageContract实现同一接口但始终NOT_CONFIGURED，所有字节操作拒绝，未验证真实S3。

Linux/POSIX独占私有root：根必须属于应用用户、权限0700、为空或有本provider根标记；拒绝符号链接路径。SecureDirectoryStream相对目录句柄、UUID键、NOFOLLOW及CREATE_NEW防止逃逸和覆盖；文件0600。根UUID写入每个元数据版本，换根后旧对象不得误读。原件不存PostgreSQL。

DB与文件系统不宣称原子。预留/配额/审计先提交，流式暂存后提交STAGED；完成命令以幂等键将FINALIZING及PENDING任务原子入库，事务外校验并创建原件，最后在重新授权事务中READY、任务DONE、事件/审计一起提交。READY事务失败可按原键恢复；有完整原件可校验重放，存在部分原件则永久拒绝该对象完成，不覆盖“修复”。用户须以新ID再试，旧记录留存。人工恢复不会绕过权限或身份隔离；不设置自动临床动作。

保守按2×声明长度扣减医院512MiB开发预算，失败也保留占用；只提供本人失败暂存对象dry run，不删除、不释放配额、不扫描或收养未知用户文件。单原件64MiB，2个I/O worker、无等待队列、30秒调用期限；64KiB流缓冲。每次Range最多1MiB，但返回前复核全件摘要。每主体每分钟60次/32MiB的尝试预算先入库，失败不返还；读取后重新授权及审计才释放响应。

部署限制：只在显式合成dev/test模式和显式本地root下启用，两个进程不能同时持有该root。不支持跨节点共享、真实S3、断电存储设备持久性承诺或生产大WSI尺寸。阻塞输入在超时后被中断，外层Servlet关闭流；真实反向代理慢客户端超时/磁盘耗尽/备份一致性/特权OS威胁须单独验收，不能用本地探针替代。对已登记READY的外部文件损坏，读取复核拒绝返回字节，历史元数据不被改写成另一个版本。

UI-042实际图片已检查，容量显示真实配置卷total/usable与数据库预留，并注明不等于医院规划容量。UI只生成64KiB/2MiB确定性合成夹具，不提供用户文件选择；大对象下载按钮明确仅前1MiB片段，完整分段API有独立审计。没有WSI格式/扫描链路已验证声明。
