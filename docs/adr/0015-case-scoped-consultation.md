# ADR0015：病例限时会诊与明确非签署采纳

2026-10-03，见[T25 PRD](../prd/development-consultation-v1.md)。在report域实现，不新增依赖或改变全局权限。

参与者集合及目的/期限固定，撤销终止访问；原workflow及diagnosis资格是前提，邀请不会扩大其原组织范围。报告内容只经具体邀请的专用会诊入口读取。当前医生和被邀请者都有服务器提交时重校验；不发送消息。

单会诊CAS序列化个人意见/汇总/确认；并行旧版本冲突须明确重读。汇总绑定最新个人意见ID与参与状态快照，确认绑定确切汇总，任何变化重新汇总。没有默认共识或票数规则。

采纳调用与原报告保存共用的事务内草稿追加边界，保留T16/T17/T18门禁；仅人工文本追加notes，旧修订不可变。报告追加、会诊来源事件、审计和幂等回执同事务。无签署/发送/临床效力。
