# ADR 0028 — 当前失效计算与独立人工复核

T38采用同步当前状态计算，不建立可能延迟的授权缓存或失效消息队列。T36 metadata/PNG和T37采纳的既有门禁不变。新增授权历史有效性事实和报告引用当前消费端点，后者还完整验证不可变产物。无需新增依赖。

模型series/state共享锁、扫描/QC/病例请求锁及当前资格锁沿用现有协议，读取与命令在短事务内重查。失效事实包括模型head/state revision、精确QC revision、扫描series head、来源QC摘要、校准及profile；影响epoch还绑定原决定、报告当前修订、分配和签署状态。相同当前事实计算相同epoch；旧模型重新启用不恢复原state revision，旧结果仍失效。重扫不自动替换原扫描或引用。

V35新增独立review/head，CAS及唯一约束、来源复合校验、append-only保护；复核与幂等及审计同事务。ACKNOWLEDGE只是知悉当前失效，DEFER保留待复核，均不恢复有效性、不修改report_revision/report_result_decision/签署/PDF。依赖变更后旧复核不算当前已知悉。当前有效消费与授权历史明确分离；历史端点不提供图像字节。

权限范围没有扩张：需当前已领取合格医生、组织/病例和既有结果所有者权限。权限撤销后历史也不可读取，管理员无例外。当前实例不提供跨医生自动移交权限或跨组织影响汇总；那些需要独立授权设计。

浏览器沿用T36每次请求检查和最长5秒已交付像素重新核验；失败取消在途操作并清空，不宣称能即时远程撤回已下载字节。T38复核表单禁止不确定写结果时切换，保留原键/原正文；取消等待不是撤销命令。没有临床批准或自动执行。
