# ADR 0029 — 本地合成医院接口契约

2026-10-04，T39；仅开发，不是医院接口批准或标准符合性声明。

采用模块化单体 `integration` + JDBC/Flyway，无新增运行依赖、网络客户端、凭据或服务。当前 Spring/PG/React/Ant Design 的依赖许可证沿用锁定基线。自定义 `SYN-HOSPITAL-1` 不是 HL7/FHIR。没有真实端点、厂商协议、支付系统或仪器认证；其能力明确 NOT_CONFIGURED。

HIS 只登记精确核心患者/申请/病例与来源身份的观察关联；BILLING 只登记合成收费请求金额（整数最小单位，上限1000000），不记支付成功；DEVICE 只记录本病例材料观察，不执行设备命令或放行 QC。以上三类共用不可变消息、出箱、去重入箱、唯一合成业务台账、接收序号和追加历史。EMR 则直接复用 T21 的确切冻结报告投递服务、出入箱、替换顺序和幂等域，避免生成第二套报告发送事实。

与核心域通过新增授权 `RequestService.caseIdentity` 和既有 `MaterialService.archiveSources` 公开投影交互。不引入全局接口管理员权限。每个命令及重放重查当前身份、工作范围、独立有期限 SYN-ADAPTER-1 资格和来源归属；资格行 SHARE 锁阻止提交期间撤权穿透。应用命令事务先锁申请行以串行化同病例接收序号，再校验 outbox CAS；不会把未知失败映射为成功。查询与审计在短事务内，写入由既有 IdempotentCommands 独占事务。

消息 DTO 白名单，UUID 核对，合成编码限定 SYN-；HTTP 最大8192字节、序列化消息最大4096字节、原因500字符、病例最多1000消息，分页20项/最多50页，单消息至多100修订。原消息与 SHA-256 不可变，新身份才能建立不同输入。摘要是本 schema 固定 DTO 的 UTF-8 JSON 字节 SHA-256；不声明可与任意第三方 JSON 序列化互通。所有记录均限定本地 synthetic，同源认证+CSRF，不接收 callback URL、路径或网络来源配置。

接收事务原子写 inbox/本地台账/接收序号/outbox/event/audit。`ATTEMPTING` 不是送达；单独 ACK 要有本地持久化证据，单独 RECONCILE 才表示本地账一致。人工操作固定当前 attempt UUID 和版本，租约30秒；尝试上限3、退避5/20秒复用 T21 DeliveryPolicy。超时只表示 ACK 未知；重启后新的尝试从 inbox 认出已落盘的同一消息，不重复写业务。乱序 NACK 保留不可变输入，仅顺序条件恢复后可带原因 REPAIR，仍受原尝试预算限制。取消不抹除已经落盘的本地记录；旧尝试不能复活取消状态。没有自动工作线程、自动诊断、真实支付或外呼。

新增真实应用子进程故障测试沿用已有一次性测试启动器与脱敏诊断：接收事务提交后 halt(23)，父测试显式注入租约/退避到期，第二个真实应用进程恢复并完成 ACK/对账。它使用测试 classpath/一次性库，不创建生产持续访问；本地未执行不能声称重启通过。真实服务/HTTP/子进程证据由完整 CI 提供。
