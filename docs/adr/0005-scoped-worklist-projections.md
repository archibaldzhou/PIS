# ADR 0005：现有流程的授权工作列表投影

2026-10-02，T15合成开发范围采用。背景：跨域分页、计数、排序和超期过滤必须使用同一权限过滤集；逐域读取固定若干条后在内存拼接会导致统计与分页不可靠。

决策：V13定义最小字段只读SQL视图，公开现有REQUEST/RECEPTION/TECHNICAL/QUALITY工作项与七域追加事件投影；应用查询在投影上统一关联当前scope/grant并过滤独立域权限。计数与分页在一条SQL快照内完成，不跨页承诺快照。投影直接使用已迁移表，是模块化单体内显式的跨域读契约；各域改变字段/状态时必须同步增量迁移和契约回归，不能把它当成可独立发布微服务。

写入仍调用TechnicalService公开领取命令，按项拥有T07事务，不写来源表、不引用内部Repository、不批量绕过版本/审计/QC。技术域只新增指定scope复核入口，保持依赖无环。不增加消息系统、同步缓存、定时器或物化视图，也不在当前缺少outbox时声称事件投递可靠。

边界：视图不是授权安全边界、RLS、临床全链记录或持久化合规审计；授权由业务入口及SQL范围条件负责。只读计数仍可能扫描较多授权数据，查询有超时且分页有界；合成测试不能证明医院规模的响应时延，真实规模前须执行计划/索引/容量验证。未来报告、WSI、AI需要各自真实状态和权限才可接入。
