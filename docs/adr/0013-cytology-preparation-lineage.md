# ADR 0013：细胞学制备台账与统一材料身份

2026-10-03，合成开发决定，依据[T23 PRD](../prd/development-cytology-v1.md)。

在 material 域增加独立细胞学标本/制备服务，复用 T13 材料、标签和QC公开接口；不引入服务间循环。三路径显式枚举，细胞蜡块无虚构取材盒或石蜡技术任务。保守合成份数与现有容器登记数相同；预留先行，完成/失败核对后才返还。

V21 以新增表、外键及明确新路线扩展约束，旧路线条件保持原样。现有质量投影增加细胞学来源依赖；报告依赖快照增加来源台账，来源撤销后不能继续使用旧就绪结论。迁移新增列会改变材料序列化依赖，既有未完成复核可能需要重新核对；旧冻结内容/PDF字节和审计不改写。DDL锁及索引只在本地合成PG验证，生产规模迁移另行评估。

库存无法与旧直制、取材盒或冰冻记录可靠核销时，禁止同容器混用入口，保留已有历史；不猜测剩余量。新身份隔离传播到整申请材料投影，即使该来源尚无输出，也阻断T16就绪。QC公开Subject状态扩展 SOURCE_QUARANTINED，旧材料状态仍保留在材料身份查询中；前端QC边界同步接受该明确失效状态。
