# ADR 0009：固定合成 PDF 与追加打印历史

状态：T19 开发实现；非临床批准。依据[开发 PRD](../prd/development-report-output-v1.md)。

## 决策

T18 的模拟签署事件唯一对应一个版本 0 产物。V17 保存确切签署、复核、报告修订、模板版本、字段模式与字段快照、依赖摘要，以及 PDF 字节、SHA256、字体摘要、渲染器版本和页数。复合外键、绑定触发器、唯一约束及不可变触发器共同拒绝串病例与就地覆盖。既有 PDF 不随模板、字体或代码变化重新生成；更正另属 T20。

复用既有 JDK 的物理字体和灰度图像能力，使用仅包含静态图像流的受限 PDF 1.4 写入器。没有新增运行时 PDF 库、远程服务或包依赖。仅需固定文本分页的合成场景，无任意 HTML、链接动作、脚本、外部 URL 抓取或用户路径。文字即使形似 HTML/URL 也只绘制成像素。替代方案是引入通用 PDF 排版库，但当前有限输出不需要其更大解析/依赖面。

随包字体由当前环境已安装 Debian Noto CJK SC Regular 2.004 离线制作并重命名，使用 SIL OFL 1.1；版权、许可及生成范围见[字体记录](../../backend/src/main/resources/report-fonts/README.md)。固定字体约 13 MB，加载时校验摘要，未知字形拒绝输出。JDK 物理字体接口依据[官方文档](https://docs.oracle.com/en/java/javase/21/docs/api/java.desktop/java/awt/Font.html)。PDF 不依赖客户端字体，但栅格文字不可搜索/选择，不提供可访问文字层、PDF/A 或电子签名，不能视作正式报告出版架构。

输入沿用 T17 模式并增加每字段 4000 字符、总文本 24000 字符等边界；最多 16 页，每页 1240×1754 灰度图、A4 页面，产物上限 4 MiB，每 JVM 同时最多 2 个渲染，合作式 5 秒截止检查。截止检查不能抢占单次 JDK 字体调用，不承诺硬实时沙箱。每页固定“合成演示／非临床报告”、页码、修订和模板版本。字体失败不回退系统/网络字体。

小型、上限明确的合成 PDF 暂以 PG bytea 与元数据原子保存，减少本地演示对象存储与数据库双写协议。此选择不适用于 WSI 或大制品，也不代表生产容量、备份或留存设计。渲染在业务事务外执行；提交时锁病例根并重新核对资格、冻结依赖和权限，再同事务插入字节、版本头、幂等回执与审计。竞争生成只保留一个产物。

预览和下载采用经 CSRF/会话保护的 POST，通过 T07 幂等事务完成授权、追加访问事件和审计后才返回字节；重试重新鉴权并返回同一产物。没有绕过审计的二进制 GET。文件名仅来自服务器 UUID；响应不缓存，含固定类型、长度及完整性头。每次读取核验保存字节的哈希。权限不可用与资源不存在统一隐藏为 404。

输出继承诊断资格、复核资格、病例和组织作用域；打印另要求 PRINT，重印要求 REPRINT，用户自报要求原请求人员及 PRINT。新增生成/打印须依赖仍有效；已存历史在当前访问授权下仍可下载，明确显示依赖已失效。重复确保已存在产物仅返回原产物，不算重新生成。所有资格/身份隔离与默认关闭的合成开关保持不变。

打印请求与用户自报结果采用追加事件，重印引用同一产物和原请求并记录原因。没有硬件反馈，没有实体打印命令，不记录“实际打印成功”。非读取事件 CAS；读取可并发追加，使用病例锁和版本头保持序列。审计失败回滚事件、头及生成产物。前端校验 PDF 长度/头部/哈希再建立内存 Blob，关闭或切病例释放；未知结果保留原键，冲突不静默覆盖。

## 验证与后续

实际渲染、逐页检查和本地测试见[T19 交付记录](../api/t19-development-status.md)。完整 Spring 编译/测试及真实 E2E 尚受 Maven BOM 缺失阻塞；PG SQL 探针和渲染器独立编译不能替代这些门禁。生产存储、受控字体更新、可访问文字层、PDF/A、设备反馈与临床签名均需另行批准和验证。
