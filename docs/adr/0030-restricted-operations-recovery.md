# ADR 0030：病例受限运维与离线合成恢复

选择：新增 operations 只读应用边界依赖 accession 公开授权接口，独立有期限 scope grant。无全局指标或无鉴权管理入口，无导出/恢复 HTTP 命令。授权行锁、REPEATABLE_READ 有界快照和访问审计同事务。只有直接关联该申请的最近20条审计元数据可见，业务正文/账号及其他病例不返回。容量只是配置根实际文件系统值。

启动时拒绝危险 Flyway 与 actuator 明细/暴露覆盖；默认配置、权限规则不变。HTTP 运维日志固定 event/服务端trace/status，无原始路径/请求/错误正文；这不是持久化合规安全事件仓库。

使用现有 Python标准库、Docker、官方固定 PostgreSQL17（PostgreSQL License）工具做真实 dump/restore，不引入依赖。无在线备份协调协议授权，故只接受脚本自身创建的停写合成源；不能接现有DB/目录。清单完成标记与严格SHA绑定、恢复新目标、实际恢复连接中断/事务回滚替代“拷贝成功就是恢复成功”。没有加密/异地/密钥实现，不伪称生产恢复工具。
