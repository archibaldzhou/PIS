# ADR0019：合成扫描导入、不可变绑定及有界尝试

2026-10-03；T29开发采纳，不是厂商/扫描仪/WSI兼容验收。已查看授权UI-038实际图片。

不引入新依赖：JDK21 ByteBuffer/SHA-256加已有条码校验器；沿用OpenJDK GPLv2 with Classpath Exception。环境未发现OpenSlide命令或Python模块，没有获批代表性SVS/NDPI/MRXS样本。适配矩阵明确NOT_CONFIGURED；TIFF大小端/BigTIFF仅识别容器magic并拒绝处理，不据容器推断厂商。ZIP/未知格式明确UNSUPPORTED，不解压、不调用shell、不访问URL、不回退不受控解析。

可执行适配只有SYNTHETIC_HEADER_V1，T28运输标记后为8字节PISSCN1换行、3个大端UUID（患者/病例/玻片）、34字节含Mod43校验的玻片条码、2个大端int（合成宽/高）。固定头98字节，每次输入≤512字节、宽高≤4096。它没有像素、层级、MPP或诊断意义，返回CONTRACT_ONLY，不能生成假预览。整对象哈希及资源上限由T28重查，真实WSI解析留待授权工具和代表性样本。

V27保存scan_grant/scan_series/scan_import/scan_event，无演示种子。任务绑定物理材料、当前病例/患者、确切T28对象和hash/大小、材料QC依赖摘要；人工声明身份独立保存，错配持久隔离。唯一object_id去重，每玻片head CAS分配序号；重扫引用确切前任务且须新对象版本，旧任务及事件不可删除。没有活动版本自动替换或发布字段。

组织READ、T28病例/对象授权及独立有效SYN-SCAN-1资格都必需；原件资格不会授予扫描资格。每次命令与读/重放重新授权。请求根锁与既有材料/QC事务协调，完成阶段重新计算依赖；源变更阻止领取或导致完成隔离。部分成功批量每项独立短事务/幂等键，结果按原输入顺序返回；DB/审计故障使当前项回滚，未知结果可整体原键重试而不重复创建前面已完成项。

领取分配30秒租约UUID及演员，最多3次尝试，5×尝试数秒退避。时间来自已有UTC Clock，单元/集成可冻结时钟，不靠sleep。解析在事务外，结果提交仍校验CAS、租约代次/演员/截止、原件权限及当前依赖。人工恢复过期RUNNING到RETRY_WAIT或次数耗尽FAILED；没有自动调度或真实扫描回调。旧回调不能重新激活取消/新代次。重复完成返回原回执，UI重新读取当前状态，不能把旧回执当当前状态。

导入成功止于PENDING_DIGITAL_QC，错误说明T30_NOT_IMPLEMENTED；所有查询publication=NOT_PUBLISHED_T30_REQUIRED。解析完成不改变材料/临床状态。UI真实批量映射每物理玻片一项、最多10项；失败项留待人工调整。保留原请求键、迟到响应取消、脏映射切换确认和独立追加历史。

限制：没有后台租约巡检、多节点时钟漂移验收、完整应用重启故障注入、真实扫描仪协议或厂商解码。持久任务允许重启后经授权人工恢复，但本地PG/格式探针不能替代完整Spring应用故障演练。需要医院批准的设备/格式/校准和T30数字QC后才能讨论后续发布，本次没有部署或外发。
