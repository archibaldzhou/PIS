# ADR0020：数字 QC 精确版本评价与合成发布

2026-10-03，T30开发采纳；只针对人工合成契约，不代表真实WSI或临床验收。已查看授权UI-039实际图片。没有新增依赖、检测算法、远程解析器或阅片器。

新增digitalqc应用边界，复用T29公开扫描查询及T28存储服务。V28保存独立专业资格、CAS头、不可变评价和追加事件；无生产种子。SYN-DIGITAL-QC-1检查单固定覆盖/焦点/缺失三项，显式UNKNOWN不得通过；通过还要求覆盖100、缺失0和无缺陷区域。这是开发契约，不是医院合格阈值。区域只对应T29合成头整数坐标，最大20、限制当前宽高；未实现像素检测或物理测量。

评价冻结确切扫描修订、物理玻片、对象ID/hash、来源摘要、检查单、演员和时间。新评价追加版本且使旧发布失效；发布/撤销另用同一CAS头，事务内追加审计和历史。数据库约束禁止覆盖历史、跨对象绑定、跳版本，以及发布非通过或非当前扫描评价。请求根锁与T29新扫描和源材料QC保持顺序；命令限时继承现有幂等框架。

有效状态是历史状态加当前依赖检查。新重扫导致旧ordinal不是序列头；取消或隔离导致扫描非待QC；来源/身份QC变更导致摘要不同；评价人或发布人专业资格撤销/过期导致消费失效。每次查询、发布、消费重新计算并显示原因，保留当时PUBLISHED事件，绝不将它直接等同当前可用。没有自动转移评价或标注。

授权需要合成工作流、组织QC、T28病例/对象范围、T29扫描资格和独立SYN-DIGITAL-QC-1。消费接口暂同样保守限制于具备这些明确权限的专业人员，管理员角色不隐式获得任何资格。T31未来消费者需显式接入本门禁，不能直接把原件保管API当数字阅片发布API。

消费要求确切publicationVersion，文件I/O前后独立短事务重新授权并核验发布/来源。I/O不持长事务，读取继承T28大小、hash、Range、速率上限，最后审计失败则不返回字节。并发撤销的线性化边界是返回前最后一次事务校验；已合法返回的字节无法远程收回。T28原件保管访问用于其独立授权的隔离调查，不等同本接口消费授权。

界面不显示伪切片、比例尺或已可阅片文案。沿用T29精确扫描入口，标明当前/历史和失效原因，手工录入新评价，不自动沿用旧表单。脏数据刷新受阻，切换通过工作区离开确认；未知写入保留原键，取消等待不等于撤销服务器动作。历史数量上限100，查询无N+1。

T29新完成错误码改为DIGITAL_QC_REQUIRED，导入端publication字段改为NOT_PUBLISHED_BY_IMPORT；同步消费者和测试，未改变导入不发布的不变量。已保存旧错误码属于历史，不回写。没有真实WSI、扫描仪/厂商链路或医院专业资格接入；这些依然是投产阻塞。
