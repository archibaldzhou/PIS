# ADR 0017：授权事件派生的固定统计快照

T27，开发决定。对应[PRD](../prd/development-statistics-v1.md)，查看UI-028/031原型图片后只落实统计与下钻；原型中的示例比率、临床承诺及导出审批不作为本次需求。

使用版本化只读SQL投影跨域读取真实保存的合成事件。先授权申请与指标，再做事件去重和首次起止配对；单SQL MVCC视图保证一次采集一致，保存有界事实及摘要，后续分页与汇总只读取同一不可变快照。选择持久化派生快照是为避免HTTP分页之间源事件变化导致总数漂移，不扩展临床状态或报告产物。

不把开放病例右删失等待混入已完成TAT，不以0替代缺失时间或空分母，不把重试和修订计作新的首次完成。QC观察最新有效评估及当前依赖状态；不是历史事件重算引擎。

统计资格独立且默认无授予，限定组织/申请，明细另行授权。所有读取重新验证原快照每一申请的当前权限，撤权则整个快照不可读，避免旧汇总泄漏。持久化限额500快照/主体；不提供销毁或自动保留期处理。

暂未采用物化视图、外部BI、CSV、日历工作时长或院方SLA；后续批准指标需新口径版本和测试，不能静默改变旧快照解释。真实医院制度、性能规模、保留策略及生产安全批准仍缺失。
