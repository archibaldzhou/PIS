# ADR 0014：染色批次冻结与一对一玻片转移

2026-10-03，[T24开发PRD](../prd/development-staining-v1.md)。在material域实现独立申请/批次，不新增域循环或依赖。

开发批次限制单病例，项目/方案使用不可变版本元数据。来源是已登记QC通过玻片，冻结时一对一转移为新材料身份，旧玻片追加状态事件并保留原QC/结果；不从未知蜡块体积虚构产率。冻结后来源依赖快照记录转移后的确切状态，后续QC/技术任务/细胞学来源变化导致失效。来源不能为旧染色输出，重跑需走原制片流程获取新来源。

V22扩展材料路线STAINED_SLIDE，并保留旧路线的全部约束。稳定source_slide_id保留完整前序链；输出玻片仍经过T14自身QC。标签内部身份分配与可用性检查分离：仅新建version0、有冻结成员的染色身份可分配条码，不支持对外打印绕过。所有标签读取/打印继续走正常来源门禁。

批次控制与成员结果追加不可变；当前有效性投影传播到材料QC、标签、T16和报告依赖。失败/撤销不能重新放行，重跑新批次新玻片。历史PDF与冻结报告不改写。新增索引/DDL锁在合成PG验证，不作为生产规模迁移批准。
