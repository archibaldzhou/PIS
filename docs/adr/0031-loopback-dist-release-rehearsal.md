# ADR0031：不引入新平台的构建产物演练

使用Python标准库HTTP客户端/服务端实现受限回环同源代理，没有额外npm/Maven/系统依赖；生产网关、TLS与公网安全另行批准。不是Vite preview或dev，直接服务manifest核对的实际dist。

release清单固定源码/构建/迁移摘要及显式37到37兼容范围。候选在独立进程通过readiness、数据库版本及再次digest检查才切换活动引用；失败保持旧引用，回滚只能选择已验证引用，不回退DB。

真实JAR演练与真实dist身份服务E2E独立：前者不装账户且默认关闭业务，后者复用既有test-classpath身份fixture验证Cookie/CSRF。T40独立非空恢复门禁必须成功，不将空schema启动说成非空在线恢复。当前是同一构建双实例回切，未验证不同历史二进制兼容。

输出限制在自身私有临时目录，子进程环境外置配置，不写密码到清单或日志。无root/外部上游/覆盖输出/已有数据库恢复入口。保留所有既有CI门禁，未新增部署平台、依赖或凭据。
