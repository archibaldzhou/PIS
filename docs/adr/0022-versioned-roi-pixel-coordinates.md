# ADR0022：像素规范坐标与追加式ROI版本

2026-10-03，限定用户授权的合成开发。沿用OpenSeadragon6.1.1/BSD-3-Clause和JDK，不新增依赖。

ROI集合绑定T31不可变manifest hash，间接精确绑定医院/病例、玻片、扫描版本、T28原件与摘要。V30外键验证绑定；集合CAS串行协调标注和校准，单ROI修订0–99、总身份50个（包含软删除）、校准20版，查询最多50项/历史100项。修订及校准禁止UPDATE/DELETE；软删除也是追加修订，不复用旧ID，不跨重扫搬运。

当前读/写沿用T30专业资格、病例/组织范围及当前发布门禁。修改或删除仅作者可执行，管理员不获得额外专业资格。事务内再次验证并持有既有病例/权限锁，CAS成功后写修订及原子审计，失败全部回滚；幂等重放重新鉴权。历史入口显式授权当前身份/范围/专业资格，允许查询旧QC依赖的记录但不返回瓦片，不恢复当前编辑或消费。没有自动降级至历史权限。撤权后浏览器在同一2秒刷新边界清理历史视图。

图像像素坐标为唯一持久化规范。矩形保存两个对角点、点一个、多边形3–32点，拒绝NaN/Infinity、越界、重复点、零面积和自交。点击落点量化至0.001图像像素；不是临床精度承诺。前端由OSD实际imageToViewerElementCoordinates提取同一仿射矩阵，叠加正变换/点击逆变换共同使用，旋转与翻转不会改写已有ROI；中心裁剪仅控制显示/输入范围，原坐标保留。独立数值模块验证旋转/镜像/平移/缩放/裁剪往返。

默认没有MPP。每版人工合成校准记录独立X/Y正数um/px、SYNTHETIC_TEST依据、原因和作者；物理测量严格绑定明确版本。未校准显示px/px²；合成校准显示合成µm/µm²，非临床。旧测量不随新校准重算；显式新修订才绑定新的校准。长度为形状闭合周长，点为0，面积由图像几何计算，X/Y分别缩放，不把屏幕像素当物理长度。

双视图独立OSD、清单、请求和ROI状态。只允许用户明确开启同一清单的像素恒等同步；不同图像没有批准映射而拒绝同步，不自动配准。切图/关闭需处理本地脏状态和未确认写入；结果未知保持原键，明确放弃后才可重新读取或离开。当前授权失败销毁OSD和ROI叠加，已合法交付字节无法远程收回，不支持离线消费。
