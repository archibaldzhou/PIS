# ADR 0011：持久化本地合成投递与不可信 CA 状态

状态：T21 本地开发；依据[开发 PRD](../prd/development-delivery-v1.md)。不具临床/法律签署或送达效力。

V19 新建不可变 report_delivery 操作、持久化 report_delivery_outbox 头、追加事件、不可变 report_local_inbox、接收端当前版本及业务拒绝审计。操作通过 FK 绑定确切病例与固定产物，产物已有修订、签署、模板和摘要绑定。创建操作、入队事件、outbox 与 T07 回执/审计同事务；其他步骤各自短事务，不持有跨步骤连接。只接收 LOCAL_SIM 目的端，不存在 URL、网络客户端、真实接收端配置或外发能力。

采用人工显式驱动的本地 worker，而非后台自动派发。每个步骤需当前会话、CSRF、幂等键、病例/组织/医生及复核访问资格。没有保存服务账号凭据或扩大持续访问。列表每页20项、最多10000页，所有成功查询追加审计。已授权病例的业务拒绝在命令事务回滚后独立记录最小错误码/动作/操作者/trace；不保存提供的正文或未经授权的对象标识。认证失败和入口不可见对象继续现有安全拒绝边界，不把通用运行日志当完整合规审计。

队列初始 QUEUED；CLAIM 使用 CAS 产生尝试UUID和30秒租约，最多3次。FAIL/TIMEOUT 进入 RETRY_WAIT，5秒/20秒退避；第3次失败及 POISON 进入 DEAD。TIMEOUT 只能回收过期租约。过期/错误/陈旧尝试 ACK 不能推进；失败后需新幂等键领取新尝试，未知结果使用原键原输入。所有时间由数据库提供；无无界自动重试。

RECEIVE 将保存的受限 PDF 字节复制至数据库本地 inbox；按投递ID去重，验证摘要及精确版本。更正/补充的前置签署来自 T20 不可变替代关系，接收方当前签署必须匹配；否则持久化 REJECTED，不静默覆盖。应用病例根锁加接收端触发器防止并发版本回退。重复接收已有 inbox 不再次更新接收端。原 inbox 和原 PDF 永久保留本次开发历史，未定义生产留存期限。

ACK 不是接收动作，必须核对当前投递、目的端、产物、修订、签署、摘要及尝试代次，同时有实际本地 inbox 证据，才置 ACKED。RECONCILE 独立核对 inbox 与接收端当前投递，匹配后 RECONCILED，不匹配 REJECTED。HTTP200 可能仅确认已记录尝试或拒绝，不代表业务已送达。新版可使未对账旧消息不再为接收端当前版；不会回退新版本。接收提交后客户端崩溃、丢 ACK 或进程重启，状态仍可查询、超时回收及去重重放；达到上限留 DEAD 人工处理，不承诺无人工介入的自动恢复或 exactly-once。

T20 的 PENDING_NOT_SENT 不改：这里只确认本地合成端，没有真实下游发送。T21 的操作/接收端记录作为独立关联证据，不把模拟 ACK 写成外部送达或替换确认。

CaAdapter 是不含签名方法的能力边界，未配置为 NOT_CONFIGURED，未验证描述为 UNVERIFIED，无 VALID 分支、密钥生成、证书或真实 CA 调用。现有合成模式默认关闭，复用隔离门禁。不新增生产依赖或修改安全配置。

前端人工阶段操作、固定目的端和精确ID核对；错误/冲突保留输入，未知结果冻结原键，切病例或投递处理脏状态并丢弃迟到响应。实际运行证据与 Spring/E2E 阻塞见[交付记录](../api/t21-development-status.md)。
