# ADR 0012：独立冰冻合成流程与追加时间/沟通事件

2026-10-03，开发决定。依据 [T22 PRD](../prd/development-frozen-v1.md)。

冰冻使用独立 frozen 域及独立资格、材料、所有者、QC、修订和事件，不强制走 T12 石蜡流程或 T16 常规诊断领取。共享公开 RequestService 身份授权、DiagnosisService 医生资格快照、QualityGate 隔离边界及 AmendmentService 常规冻结版本查询。单向依赖，不反向引用 frozen。

申请根 UPDATE 锁串行化冰冻与既有身份/QC/常规写入；资格行 SHARE 锁保护撤权；全局冰冻 CAS 防止并发阶段、转交、复核或沟通覆盖。复核摘要覆盖冰冻修订、所有者、QC事件、时间事件、当前医生资格及申请QC快照。读取动态检查有效性，复核提交对比当前操作者读取时的依赖令牌；即使来源QC变化没有更新冰冻CAS，也不得静默绑定新依赖。历史复核不删除。历史事件、修订、常规关联采用追加表及禁止 UPDATE/DELETE 触发器。

独立人工合成 QC 不代表医院验证。现有来源材料有未通过QC时保守阻断冰冻临床文本操作；未建常规材料不构成强制石蜡前提。唯一沟通方式 LOCAL_SIMULATION，没有外部调用；回读/确认必须由目录中的接收者会话分别记录。新依赖、密钥、调度任务均不引入。

V20 在既有报告修订/复核表新增两组唯一键供精确版本复合外键引用，会建立索引并取得表锁。本地数据量验证不代表生产在线迁移能力；上线前须按目标数据量评估锁窗口和索引策略，本任务不部署。冰冻 stage 是根据不可变事件指针生成的结构化列；当前资格失效时 UI 显示 REVIEW_INVALIDATED，不能仅据历史 REVIEWED 认定有效。
