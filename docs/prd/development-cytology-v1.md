# T23 细胞学制备来源链开发 PRD v1

2026-10-03，用户授权的合成开发规格，不是医院工艺或临床批准。已读取本环境授权 ZIP 并查看 UI-015 实际图片（附件 SHA256 `74f3305da4278f84c7660eb13625c1ff604174116d2fe13fbeffe85cf7a58291`）。采用来源、制备方法、可选细胞蜡块及玻片谱系布局；不实现临床分类、初筛结论、默认阴性或 AI。

## 业务模型

已接收容器登记独立细胞学标本 UUID，保留患者/申请/病例/容器 UUID。起始库存严格来自接收容器登记的材料数量，单位固定为 SYN_PORTION（合成份数），不从份数推断体积、细胞数或临床制片产率。已有旧版材料、取材盒来源或独立冰冻材料的容器不能直接纳入新台账，避免重复计算未经核对的剩余量。

独立资格 SYN-CYTOLOGY-1 按范围授予制备和来源QC能力，同时要求现有 MATERIAL/QC 权限。来源登记后 PENDING，需要显式人工合成QC通过。身份不符不可在本模块解除。来源QC每次变化递增独立代次；旧制备不能因为重新通过而自动恢复有效。

三类路径 DIRECT_SMEAR、LIQUID_BASED、CELL_BLOCK 均需人工制备元数据（分别为人工涂片方法及固定记录、液基介质及制备方法记录、细胞蜡块制备及包埋记录）、转移数量、原因。创建制备立即从来源可用量预留，生成独立制备 ID；再次制备引用同来源旧制备 ID 并填原因，新建全部身份，不覆盖旧记录。

完成时核对已转移量＝消耗＋废弃＋返回。玻片数不得超过合成消耗份数，单次上限20；这只是保守开发数量规则，不代表临床产率。直接/液基路径生成独立玻片且 block_id 为合法空值；CELL_BLOCK 路径生成独立细胞蜡块及绑定它的新玻片，明确保留共同制备来源。后续追加制片走新制备及新消耗，不使用常规石蜡任务伪造细胞蜡块来源。失败制备无产物，必须核对返回/废弃，不凭空补库存。

材料使用 T13 material_entity、UUID、条码与 label_identity；新增明确细胞学路线及制备外键，不放宽原有三条路线约束。纳入台账的容器禁止继续用旧直制、取材盒或冰冻登记入口绕过消耗。材料重打保留原ID，新制备/玻片均新ID。保留来源、数量事件和操作人；历史只追加。

## 门禁与接口

来源QC、身份、制备状态和所绑定QC代次均影响输出有效性；材料自身仍必须通过现有QC才可进入T16和后续报告。来源撤销阻断标签、QC与诊断就绪；报告依赖包含细胞学来源和制备快照。既有角色、默认关闭合成开关及 dev/test 边界不变，管理员不自动取得资格。

申请根锁串行化同病例操作；来源库存CAS与制备CAS同时校验，当前授权在事务中重读；数量核对、产物、条码、历史、审计与幂等回执同事务。跨医院/患者/病例由复合FK及服务端授权共同约束。界面明确人工输入、路径切换清理不适用字段、脏输入取消、迟到响应隔离和原键重试。没有设备、外发或临床签署。

## 验收及限制

覆盖三条路线、无蜡块合法性、来源复合键、保守数量边界、预留/消耗/返还、重复准备及请求、旧QC代次、失败、并发消费、权限撤销、历史不可变、审计回滚、UI及真实本地E2E源码。Maven缺失BOM继续阻塞时，如实区分可执行PG/Java探针与未运行的Spring完整测试/真实E2E/CI。医院计量单位转换、设备产率、跨容器混样/拆分、真实工艺参数与临床术语不在本开发规格内。
