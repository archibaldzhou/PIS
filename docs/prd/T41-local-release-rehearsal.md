# T41 构建产物与隔离部署/回滚开发 PRD

2026-10-04；用户授权的本地/CI合成演练，非生产部署批准。沿用AGENTS、T40配置/审计/私有对象契约。无新凭据、外部域名、TLS、监控或宿主安全修改。

## 实现与验收

- 固定现有构建工具，release清单绑定真实Spring Boot JAR与前端dist所有文件SHA256、源版本、V1–V37迁移摘要以及明确兼容区间[37,37]。清单可重复生成，不用构建时刻影响digest。拒绝缺件、路径/链接逃逸、错误hash、测试fixture打入正式包及无明确兼容范围。输出只新建，不能覆盖已有release。
- Python标准库本地同源反向代理：非root、只监听127.0.0.1、固定loopback后端端口、私有无日志正文。实际服务dist，无Vite运行时；SPA深链接/刷新、正确MIME、未知资源/API错误、Cookie/CSRF保持。API不回退index，不跟随重定向，不接受外部上游或路径穿越；有界并发/体积/超时。
- 临时目录内候选启动与健康检查；只有readiness通过且迁移在兼容区间才原子切换。失败版本保持旧活动产物；回滚仅切换已验证产物、不降级迁移或覆盖DB/对象。独立测试schema、新进程冷启动/重启、失败候选及切回旧版；沿用T40实际PG/对象恢复门禁。
- 真正打包JAR的启动演练进入CI，使用既有_test库中自身创建schema，配置外置，合成工作流仍关闭。真实前端dist+同源代理E2E使用现有一次性后端身份fixture验证会话、CSRF/拒绝、刷新和错误；明确区分fixture服务和真实打包JAR验证。
- 本地若缺BOM，不能声称真实打包JAR/服务通过；实际dist浏览器截图和代理HTTP契约仍执行。TLS/域名/外部依赖均NOT_CONFIGURED，不表示production ready。

不更改默认临床禁用，不新增实际部署平台。保留全部现有CI测试和超时；新增演练单步有界。T41独立提交validation/t41，完整CI由父会话核验后才可整理main。
