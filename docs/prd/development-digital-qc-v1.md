# T30 数字扫描 QC 开发 PRD v1

2026-10-03；用户授权的本地合成开发，非医院批准的临床规则。已查看授权 UI-039《数字切片质量检查》实际图片。沿用人工检查、缺陷记录、隔离与重新扫描语义；不复制原型中的假切片、比例尺或阅片器。T29 只有合成文件头，没有可评价的真实图像，所有评价均为人工输入的合成契约测试。

精确绑定 scanId、scanVersion、slideId、objectId、SHA-256、来源摘要和扫描序列号。检查单 SYN-DIGITAL-QC-1 不可变：覆盖、焦点、缺失区域/瓦片三项必填，各值仅 PASS/FAIL/UNKNOWN；覆盖比例0–100，缺失瓦片数非负，缺陷区域为当前合成宽高内整数矩形，最多20个并有人工备注。只有三项明确PASS、覆盖100、缺失0且无缺陷区域才能通过。未知、缺项、不一致绝不默认为通过。不作算法检测、临床准确性或医院阈值声明。

组织及病例READ、T28对象权限、T29扫描资格与独立有效SYN-DIGITAL-QC-1审核资格并行检查，管理员无隐式权利。查询/命令/重放/消费在服务端重新授权。保存评价生成追加版本；修改评价必然撤销先前发布。发布为显式独立CAS操作，只允许当前扫描序列头、身份/来源仍有效、精确扫描修订匹配、评价人员资格仍有效且所有必需项通过。撤销有强制原因，完整历史不可删除。新扫描、取消、来源QC或身份变化后旧发布的有效资格即时失效，历史发布记录仍保留，不能自动恢复或转移评价。

发布仅表示合成契约可经专用消费端点访问，响应明确无图像/阅片能力（T31未实现）。消费端点绑定当前发布修订并在文件I/O前后重查，沿用T28哈希、Range、限流和审计；撤销竞态不返回旧资格结果。T28原件保管接口继续允许其独立授权人员检查隔离原件，不代表阅片消费资格。前端不把保管下载当已发布阅片。

请求根锁协调T29重扫、QC、身份与本域CAS，业务/评价/事件/审计同事务，I/O在事务外。每对象最多100次QC变更，历史有界。UI切换病例/扫描清理旧状态、脏表单确认、取消等待、原键重试、迟到响应隔离；显示当前/历史扫描、确切hash、失效原因与人工缺陷，不造图像。补齐权限、未知/失败、源变更、撤权、重扫、竞态、审计回滚、下载和真实E2E/UI测试。

开发模式默认关闭，不接真实患者/扫描仪/CA，不外发部署；完整后端/真实E2E如受本地BOM缺失阻断如实登记，父会话按提交SHA验CI。真实WSI/厂商格式及像素级覆盖检测仍未验证，不宣称可临床使用。
