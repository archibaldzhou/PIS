# T21 本地合成投递开发 PRD

用户授权开发，非医院规则批准。已查看当前附件 UI-024 实际 PNG；来源与 T20 相同，原始招标正文仍不可读。继续原环境与历史，不 push、部署或连接外部系统。合成模式保持默认关闭。

采用人工驱动的持久化本地队列：显式入队→领取尝试→本地模拟接收→验证业务ACK→对账，每步独立短事务、当前权限及原子审计。没有后台自动临床动作或网络传输。唯一目的端 LOCAL_SIM；不接受 URL。outbox 绑定病例、不可变产物/修订/签署/摘要、前置签署及发起人；inbox 按投递ID去重，保存受限PDF副本和业务确认。接收方当前版本须匹配 T20 原签署，替换后保留所有旧 inbox，不改 T20 不可变关系。

状态区分 QUEUED、ATTEMPTING、RETRY_WAIT、ACKED、RECONCILED、REJECTED、DEAD。领取产生新尝试UUID与30秒租约；最多3次，失败后5/20秒退避，过期必须显式超时回收。旧尝试ACK不能推进新尝试；接收后崩溃可重试读取原inbox而不重复替换。ACK核验投递、病例、目的端、修订、签署、产物、哈希及当前尝试，并必须存在本地接收证据；HTTP成功不是业务ACK。对账再核对接收端当前版本。毒消息/版本拒绝进入人工处理终态，不无限重试。

所有查询和动作继承报告资格、组织及病例授权；查询也追加审计。发起新入队与实际接收重新核验当前冻结依赖；既有ACK/对账可以追踪历史，但不能复活旧消息或静默回退接收端。显式CAS、幂等键及原因必填。UI提供阶段、尝试、错误、原因及版本信息，取消/脏输入/迟到响应/原键重试，全部注明合成模拟、无临床或法律效力。

CA仅定义不产生签名的适配接口，默认 NOT_CONFIGURED，提供的未经验证描述返回 UNVERIFIED，无VALID状态、无密钥、证书、持续访问或真实CA调用。

测试迁移、事务回滚、并发、去重、错ACK、乱序、迟到/超时、租约恢复、有界重试、替换拒绝、撤权与UI；真实E2E仅连接本地Spring与数据库模拟接收端。完整后端如仍缺BOM，明确未验证，不把局部探针当可合并/投产证明。
