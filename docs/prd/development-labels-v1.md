# T10 开发规格：容器标签与身份追踪 V1

2026-10-02。用户授权自行编写缺失 PRD；依据已实际查看 UI-007。仅合成 dev/test，继承默认关闭开关，不表示医院模板/设备/编号获批。不包含 T11、蜡块/玻片业务或真实打印机。

- 仅已接收申请中已关联病例的容器可生成标签任务；容器 UUID、开发标签条码、病例号、任务 UUID 分离。首次分配独立随机条码身份，保存后不可变；重打不得新建容器、改患者或更换条码。
- 独立 PRINT、REPRINT 权限，均要求 READ；REPRINT 还要求 PRINT。既有 WRITE/RECEIVE/管理员不自动获权。所有列表/详情/预览/校验/命令重新检查容器所属申请及作用域。
- 首次创建校验申请和容器版本，唯一根任务。同幂等键重放原回执、异参冲突；已有根任务须走重打。重打必填原因并绑定原任务版本，新建子任务且推进父任务版本，保留原模板/身份快照。
- 模板固定 `SYN-CONTAINER-1`，只展示开发水印、患者UUID/合成姓名、就诊号、申请号、病理号、容器UUID、部位/侧别、条码、任务ID/模板版本。首次任务冻结这些字段，重打沿用快照。本版不得编辑打印正文或传入任意模板/打印机地址。
- 条码为随机UUID形成的 `S`+32位大写十六进制+Code39 Mod43校验字符；不含姓名/诊断，唯一对应同一容器。预览以Code39黑白条带表示完整内容，含起止符和静区；扫描输入须格式/校验和/确切任务容器一致。实物可读性/尺寸/DPI仍待设备验证，不能作为临床标签。
- 状态只有 PREVIEW_READY（可预览，未证实打印）、FAILED（开发适配器模拟失败）、CANCELLED。创建/重打只生成预览任务。没有 PRINTED/SUCCEEDED；浏览器打印对话框关闭不产生成功记录。
- 受控开发适配入口只允许将 READY模拟失败（说明必填）；FAILED可带原因重试到READY，沿用同任务/条码，增加尝试次数与版本；READY/FAILED可带原因取消，终态不可重试。重打新子任务可从任何现有任务发起，表示新意图而非恢复取消任务。全部操作逐条留事件、当前操作者、时间及原因，业务/审计/回执同事务。
- 预览以服务端当前授权读取为准；UI开/关不改变任务状态。打印按钮只在用户点击时打开浏览器对话框，明确无法确认物理输出；无后台自动发送、网络打印机或外部回调入口。
- 列表每容器最多最近100任务，单任务最近100事件，完整历史保存；固定排序。状态/版本冲突要求刷新，未知结果保留原键/输入并锁定操作；切申请/容器/退出清理内存，未确认命令不能普通导航。
- 数据库增量V7，保留V1–V6。测试包含迁移、跨范围/低权限、重复/异参、旧版本、故障回滚、重打身份一致、取消终态、真实HTTP/浏览器闭环和条码校验。验证分支全套CI通过后T10独立整理main。

医院标签内容、编号命名空间、DPI/纸张/设备驱动、扫描校验方式、重打审批/标签回收、患者更正/重扫时旧标签失效、留存期限均未批准；仅阻断实物/临床验收，不阻断上述开发闭环。
