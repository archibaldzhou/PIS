# T31 合成多分辨率阅片开发 PRD v1

2026-10-03，用户授权合成开发；已查看授权UI-040实际图片，不采纳临床放大倍率、比例尺、测量或AI声明。开发开关默认关闭，所有源为明确合成RGB几何图，不接真实WSI、设备或患者。

使用固定OpenSeadragon 6.1.1（BSD-3-Clause），npm官方注册表锁定完整性，前端本地打包，无CDN。JDK ImageIO只编码自己从有界原始RGB创建的PNG，不解码未知文件。T29增加显式PISRGB1合成格式，精确UUID/条码头及像素长度；尺寸最多512×512，全部字节小于1MiB。原仅文件头格式不提供假图，真实厂商格式仍UNSUPPORTED/NOT_CONFIGURED。

瓦片tileSize128，层级0..ceil(log2(max尺寸))，最近邻确定性缩小；每瓦片/缩略图PNG有SHA-256，清单绑定医院/病例/玻片/扫描修订/T28原件版本及hash/生成器版本。V29仅保存不可变清单元数据，像素不入关系表；重建须得到完全相同摘要，否则失败。prepare显式幂等命令，生成在事务外，落库前再次验证T30当前发布与资格，审计同事务。

manifest、缩略图和每瓦片每次请求（含服务端缓存命中）先后校验T30确切publicationVersion、当前来源和权限。服务器缓存仅内存、16MiB/最多8幅、LRU，键绑定医院/扫描/原件hash/生成器；没有授权结果缓存或公开HTTP缓存。每用户每分钟240次请求、32MiB，单次生成最多2并发、5秒截止、没有等待队列；路径只接受整数坐标/UUID，禁止URL、任意路径和远程读取。

UI实际使用OpenSeadragon平移、缩放、适配、导航图和键盘；显式加载/错误/缺失瓦片与人工重试，不将空白当阴性。A/B切换取消旧请求、销毁实例和缓存，过期响应不得回填。浏览器私有有界图像缓存不持久化，定期及交互时重新核验manifest授权，撤销发现即销毁/清空。已合法交付到终端的像素无法远程收回，前端检测间隔明确为2秒，不声称即时抹除已交付字节。T32校准未知，不展示物理比例尺或测量功能。

验收：真实PNG magic与hash、坐标/层级边界、清单一致性、各资源授权/撤销/缓存命中、并发和审计回滚、取消与连续切换；真实浏览器截图并检查像素确有合成图像。真实E2E建立T28→T29→T30→T31来源。缺失BOM阻断的完整后端/E2E诚实单列；独立validation/t31待父会话CI核验，未绿不合main。
