# T40 合成运维与隔离恢复开发 PRD

状态：用户授权的开发范围，非医院制度或生产灾备批准。2026-10-04。

已实际查看合法附件 UI-035 审计查询与安全事件、UI-036 停机登记与恢复对账 PNG。采用只读状态、明确失败/待核对及关联追踪；不实现原型中的临床停机补录或外发导出。

## 契约

- 保留默认关闭的合成工作流。配置启动检查拒绝公开管理端点、详细健康、危险 Flyway 开关及非隔离开发组合；不修改部署配置或身份权限。
- 病例运维 GET 使用现有登录与病例范围，再检查独立有期限 SYN-OPS-1 只读资格；管理员无默认资格。查询在短事务中授权、快照读取、追加审计；失败不能显示空数据。只返回有界计数、枚举和本病例直接审计事件（不返回正文、路径、账号、密码或凭据）。
- 日志使用服务端 trace UUID 和固定事件代码，不接受任意文本；健康公开响应仍不含明细。根目录容量仅取实际 provider 值，未配置/失败用 null 和明确状态。队列失败数量来源实际状态，阈值无医院 SLA。
- 恢复工具只创建自己的隔离无网络临时 PG17 容器、临时数据库和私有目录；不接受连接串或现有恢复目标。应用不运行的停写测试源应用全部迁移，生成明确合成身份、审计、幂等和不可变对象。持有数据库只读一致快照及源文件冻结期间生成实际 pg_dump、SHA-256 清单，恢复至新建测试数据库和新对象目录。校验完整数据库摘要、身份/FK、幂等/审计行与对象字节/哈希/引用。损坏、缺失、额外对象、版本或中断标记未完成一律拒绝，不复用部分恢复目标。
- 此工具是可执行合成恢复演练，不是任意业务库备份入口。没有实际密钥管理、加密、异地备份、在线一致性或医院 RPO/RTO 承诺；UI 明示 NOT_CONFIGURED/NOT_VERIFIED，不声称此实例已备份。

## 验收

权限撤销/跨病例拒绝、审计失败整体回滚；配置失败与日志不含提交文本；未知容量不显示零。UI 取消、请求失败和切换丢弃迟到响应。真实 PG dump/restore、源版本清单、损坏/缺失/中断/危险目标拒绝及恢复后引用验证，纳入 CI。保留所有既有测试和单步超时、verify 30 分钟。完整 Spring/E2E 本地依赖阻塞如实记录；不以独立探针替代完整服务通过。
