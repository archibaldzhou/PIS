# T17 结构化报告草稿开发 PRD V1

2026-10-03，依据用户明确的T17范围及T16开发契约。当前环境已查看授权UI-020实际图片；仅合成开发，不替代医院报告模板审批。原型的自动保存、复核提交、切片器、AI或附件不在本次范围。

病例只允许当前ACTIVE持有人且具有效can_diagnose资格读取/编辑草稿及历史；分配员或管理员不默认获权。读取可显示QC阻断，保存必须重新验证接收、资格、归属、assignmentVersion、QC及身份隔离。转交后旧医生不得读取或重放，受让人明确领取后可见历史。沿用默认关闭的合成dev/test模式。

模板由不可变(templateCode,templateVersion)标识，schemaCode绑定明确验证器。无在线模板修改/发布接口；生产迁移不种演示模板，仅测试夹具显式配置两个合成版本。SYN-TEXT-1要求gross/microscopy/diagnosis/notes四个字符串，单字段最多4000字符，空字符串允许保存未完成草稿；SYN-STRUCTURED-2额外要求sampleCount为0–1000整数、manualChecked为显式布尔值。字段对象序列化UTF-8最多32000字节；既有schemaCode的验证语义不可修改，规则变化必须新增模式和模板版本。未知字段、缺字段、null、数字字符串、浮点计数、未知模式均拒绝。不生成任何诊断或自动填入结论。模板元数据不是临床批准。

每病例一个草稿头，初始version=-1，首次保存v0。每次保存追加不可变修订，保留模板版本、完整字段快照、作者、时间、原因和当时分配版本。头指向同病例确切修订。expectedVersion及confirmedCaseId必填，CAS冲突不能静默覆盖；模板切换也是新修订，旧正文和模板保持。历史按版本分页，单页最多20项。

T07拥有短事务：锁当前资格→申请根锁→复核归属/版本/QC→追加修订与更新头→原子审计及幂等回执。重放也核验当前持有人资格，不越权返回草稿；键摘要含全部字段、模板、版本、原因和病例。审计失败全部回滚。

UI从诊断队列选择病例，显示病例/患者/申请/分配版本/草稿版本。切模板明确确认清除本地输入，取消保留；切病例、范围、离开和刷新有脏提示；等待确认阻断导航，原键原输入重试。旧病例迟到响应丢弃。仅保存草稿，无复核、签署、发送、CA、AI、自动保存或部署。

覆盖权限/跨病例/当前持有人与QC、严格类型及模板版本、并发CAS/幂等/审计回滚、迁移不可变约束、UI切换与迟到/断网/双击、真实E2E人工草稿链。完整Java和Spring E2E若依赖不足明确记为未验证；仅本地中文独立提交，不操作GitHub。
