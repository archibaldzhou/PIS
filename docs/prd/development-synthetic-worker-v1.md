# T35 持久化合成契约任务开发PRD v1

用户授权合成开发；已实际查看合法UI-044。仅技术契约worker，没有诊断模型、权重、推理、训练、GPU或外部服务。T34 executionAllowed=false不改变。新增独立pis.ai.synthetic-worker-enabled开关，默认false，仅dev/test可启用；独立限时合成任务资格叠加已有病例/医院/组织/存储/扫描/QC/模型授权。

任务绑定确切适用判定、扫描对象/hash、身份/QC发布版本、模型/预处理/配置摘要，持久化任务、尝试、outbox、回调inbox和追加历史。QUEUED/RUNNING/SYNTHETIC_SUCCEEDED/FAILED/CANCELLED/TIMEOUT/UNSUPPORTED/INVALIDATED分别表示技术状态，未知进度null。所有成功仅技术合成夹具完成，绝不生成诊断或临床许可。

当前开发worker由有权限的原提交者以已认证会话显式驱动，可有并行进程/会话，不创建后台服务身份或新凭据。数据库最多2个有效租约；30秒租约、120秒尝试截止、最多3次尝试，按明确合成退避规则人工重试。领取、心跳、取消、超时对账、重试及回调都CAS/幂等；回调绑定schema、lease、generation、actor和不可变产物hash。取消/过期/旧generation不接受迟到回调。

开始、续租、最终接受和消费均重新验证当前适用性。QC、模型、资料或身份变化使当前资格失效；保留历史，不把旧成功当临床结果。owner限定是本阶段明确限制，不声明跨身份自动调度。提交、outbox与审计同事务；产物经T28独立暂存/校验/finalize，不假装文件系统和DB原子。崩溃后按已保存尝试和稳定存储键恢复，未接受或旧尝试产物只保留不可变历史，绝不自动删除或暴露。

产物是最多4KiB的固定合成技术文本，有独立用途；原件API不直接提供此用途的字节，必须走任务当前授权与依赖核验的消费入口。UI从当前扫描契约入口提交，展示准确任务/尝试/未知进度/错误，支持显式领取、技术运行、取消、有限重试和对账；迟到请求、切换、脏表单及原键确认不串任务。

覆盖真实引擎并发、租约/截止/退避、回调重复和错身份、取消/撤销竞争、审计回滚、存储部分提交与恢复、独立JVM崩溃后恢复（CI）、HTTP/E2E/UI。当前本地Maven缺BOM则记录未运行完整后端/服务E2E/全进程重启，独立PG探针不替代。独立中文T35提交到validation/t35，CI通过前不合main，无部署和外发。
