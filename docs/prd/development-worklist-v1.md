# T15 工作列表、批量领取、合成超期与追踪开发规格 V1

2026-10-02，用户授权开发规格，仅默认关闭的合成dev/test。已重新验证授权ZIP摘要，实际查看UI-001工作台、UI-006病例谱系、UI-008队列；UI-037部分成功/并发提示沿用已查看原型。原型中报告、扫描、AI等未来模块不进入假造统计。

## 工作列表

统一列表只聚合现有REQUEST、RECEPTION、TECHNICAL、QUALITY四类对象及当前真实状态。每行有kind+稳定实体ID、申请/患者ID、显示申请号、当前版本、开始时间、必要的来源盒和是否隔离。REQUEST依赖READ；RECEPTION还需RECEIVE、TECHNICAL需PROCESS、QUALITY需QC。查询、统计、筛选、分页和排序均在服务端同一授权过滤集上完成，隐藏模块不通过计数泄漏。授权范围不可由客户端患者ID覆盖。

分页1起、每页1–50条，固定排序OLDEST/NEWEST/NUMBER并按kind/ID稳定断并列；枚举状态/类别筛选，未知值400。只返回当前页，计数与行使用同一SQL快照；列表不是跨分页的一致快照，不保存跨页全选。

## 超期提示

只对未结束的既有工作项计算：申请草稿/待接收、接收待办/异常、非终态技术任务、未通过/隔离的有效材料QC。采用服务端配置pis.worklist.synthetic-due-minutes（默认240，允许1–10080），从对应记录创建时间开始；严格晚于截止时刻才超期，恰好等于不算。统一asOf及配置值随响应返回，结束项不超期。不计医院工作日/节假日/临床优先级；这是合成演练阈值，不是医院TAT或SLA，也不自动执行任何动作。

## 批量操作

仅支持既有技术任务CLAIM（领取）。每批1–20项，只限明确选中的当前页任务；显示每项申请/患者/盒ID/版本，填写共同原因并确认。禁止跨页默认全选、隐式包含过滤外对象、批量QC通过或异常放行。

各项调用T12领取命令，独立事务、当前权限/范围/源盒/隔离/版本校验、审计和幂等。使用UUID batchId与taskId派生稳定逐项键；同批同项修改版本或原因属于异参冲突。重复任务/超量/非法输入在任何写入前拒绝。外层不包装大事务，不嵌套T07。

响应逐项包含原任务ID、HTTP语义状态、明确SUCCESS/REJECTED/UNKNOWN、安全错误码、成功回执版本及是否重放；没有“整批成功”伪装。跨范围/不存在统一不可访问，不返回其存在性或元数据。已成功项不撤销，未确认项用原batchId和原输入确认；明确失败后需刷新重审，不能改原键输入。网络中断不等于整批回滚。最多20项是开发上限，不是容量承诺。

## 全程追踪

按已授权申请稳定ID查询现有申请审计、接收、取材、技术任务、材料、标签、QC追加事件，按时间+domain+事件ID稳定分页（最多50）。每项只展示实体ID/版本、动作、因果关联ID/类型、服务端时间；不输出患者姓名、病史/诊断正文、任意原因正文、凭证或原始HTTP负载。各域事件按相应独立权限过滤，计数同规则；无权与不存在均404。不是临床全链闭环，尚未实现模块不显示伪事件。

## 验收

默认授权拒绝、跨患者/组织/范围替换、被撤权的计数与查询、未知筛选排序；严格超期边界与可配置值；逐项部分失败、双击重放/同键异参/审计回滚、并发失效和QC隔离；UI换页/筛选清空批选、离开脏输入确认、未知结果原键重试、错误与空数据区分、真实UI/API闭环。新增V13只读投影视图，不改V1–V12；无需新增中间件。验证分支validation/t15-20261002完整CI成功后独立main，不包含T16或部署。
