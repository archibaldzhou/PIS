2026-10-03；用户授权的开发规格，不是医院制度或临床批准。仅 dev/test 且现有合成开关开启时可用，默认关闭。不生成诊断、不外发、不调用设备/CA、不部署。

## 原型与边界

当前环境读取用户授权 ZIP，SHA256 `74f3305da4278f84c7660eb13625c1ff604174116d2fe13fbeffe85cf7a58291`；已实际查看 UI-016 术中冰冻工作站及 UI-025 重要结果沟通。采用材料来源、人工时间线、意见、对象身份和回读布局。原型“通知/关闭”改为独立的本地合成沟通、回读、确认记录；不证明真实送达。无医院 TAT 阈值、自动升级、自动诊断或消息。

## 独立模型与规则

每个已有合成病例可创建一个独立冰冻申请/工作记录，独立 UUID、材料 UUID、来源容器、人工采样部位与接收时间。病例/容器必须同申请、同医院。来源申请须已核对接收；不要求石蜡技术任务、常规诊断分配或常规报告。独立冰冻资格显式授予记录、QC、复核能力，且医生资格/工作范围仍有效；管理员不自动获得资格。冰冻所有者可转交给当前合格人员，新所有者重新领取。QC 为冰冻独立判定；来源申请存在身份隔离或非 PASS QC 时阻断，不能借新模块解除隔离。

接收→制备→人工草稿→合成复核；QC PASS 是草稿/复核/沟通前置。转交、QC 变化、时间更正、新草稿及资格变化使既有复核不再就绪；历史不删除。复核提交携带读取时的依赖令牌，来源QC等依赖变化即拒绝旧输入。复核必须由不同于草稿作者的显式合格人员操作，这是仅开发策略，不推断医院签署规则。未复核不允许沟通。

时间输入必须带显式 UTC offset 与 IANA zone，验证该时区真实 offset（包括夏令时），不得未来发生。发生时间和服务器记录时间分存；迟补允许但仍校验顺序；接收/制备更正追加事件引用原事件及强制原因，禁止覆盖。结果草稿、复核和沟通均绑定精确修订。时长仅基于人工接收/制备记录计算，非临床时限。

沟通对象必须是同范围当前有效的合成账号（由服务器目录核实），发送/记录人来自当前会话且具资格；方式仅 LOCAL_SIMULATION。不拨号、不发消息。COMMUNICATE、READBACK、CONFIRM 分别追加，回读/确认必须由该接收者本人记录，带人工证据文本；标识为 SIMULATED_RECORDED，永不表示真实接收。新沟通不继承旧回读或确认，迟到事件必须引用准确沟通 ID、修订和当前 CAS。转交后旧复核阻断新沟通，历史仍可查。

常规关联绑定同一病例的确切已模拟冻结常规修订及模板版本，通过既有公开授权接口检查。保存精确冰冻修订/复核、常规模拟签署 ID、差异状态、一致/不一致的人工解释；追加记录，不覆盖双方。旧关联仍展示为历史，不隐式更新至新报告。

## 事务、授权与验收

所有入口重新核验医院/组织/病例范围、独立资格和合成开关。命令先锁申请根，再读取当前授权、状态、身份/QC和版本；CAS、幂等回执和成功审计同事务。撤权重试不得重放成功。未知对象和越权统一404，记录正文不入日志。读取分页，事件和修订追加不可变，关系复合外键。UI 切病例/阶段先处理脏输入，迟到响应丢弃，未知写结果保留原键重试，取消不撤销已发请求。

验收包括时区/顺序/迟补更正、独立沟通状态、版本/QC/资格失效、转交、重复/并发/CAS/幂等/回滚、同病例常规差异历史及 UI。补充真实 PG/HTTP E2E 源码，实际执行能力逐项记录；Maven BOM 缺失时不得声称 Spring、真实 E2E 或 CI 通过。
