# T38 合成结果失效与人工复核 PRD v1

用户授权开发，非医院/临床批准。原环境已查看授权 UI-047 运行监测/版本验证与 UI-046 人工复核实际PNG；采用原版本保留、失效原因、明确人工理由/确认和历史区，不复制原型示例性能指标。

采用提交/读取时的当前状态计算，不依赖异步通知成功或前端缓存。T36结果与瓦片、T37新采纳继续走原资格/QC/版本门禁。新增每笔人工决定的影响视图：精确旧result/模型/输入/目标/采纳修订、当前依赖版本与原因、内容不变的已签状态、当前可消费与历史只读区别。模型停用/退休/版本变化、扫描重扫、QC撤销或身份变化均失效；重新启用也不会自动让旧版本有效。

对具体决定追加人工复核ACKNOWLEDGE（已知悉并保留失效）、DEFER（待后续处理），必须当前有资格且已领取病例的医生，兼具现有结果/组织资源权限，理由1–500、显式确认。复核绑定影响snapshot hash、当前报告revision与分配版本；CAS每决定0–99，幂等和审计同事务。确认只改变复核待办展示，不恢复可消费、不改写报告/原决定、不重新推理/采纳/签署；更正报告须原有单独流程。依赖再次变化生成不同snapshot，旧复核不再算已知悉。

历史视图可见旧绑定及当时复核；当前引用消费端点只返回当前目标修订且当前有效的ACCEPT_REFERENCE，失效一律409，无权限404。历史PDF按原有不可变/授权流程保留，不能将历史下载称为当前有效结果。无全局未授权聚合：从授权病例/结果决定历史逐项进入，每决定最多100条记录。

UI按当前决定打开影响面板，显示原因/精确版本/待复核，明确确认；处理中阻止切换，取消等待后原键重试；切换/卸载丢弃迟到响应。刷新不静默覆盖脏理由。结果图层保持有界周期和每次请求重新鉴权、失效即清空；已交付像素最多5秒检查间隔，不宣称瞬时远程撤回。

测试覆盖模型/QC/重扫、再次变化、重复/乱序重放、并发、审计回滚、冻结报告不变、权限、真实HTTP及E2E、UI取消/脏表单/迟到/实际截图。临床executionAllowed=false，开发默认关闭，合成数据，不外发/部署/真实模型。本地BOM缺失如实报告，不用独立探针代替完整后端。
