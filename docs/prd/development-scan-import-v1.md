# T29 扫描导入开发 PRD v1

用户授权的本地合成开发；已查看 UI-038 扫描任务与导入实际图片。开发模式默认关闭，不接扫描仪、外部URL或真实患者。不包含T30数字QC或阅片发布。

每个任务绑定医院/病例/患者/物理玻片、材料与QC依赖摘要、T28确切不可变对象版本/大小/SHA。资格为独立有效SYN-SCAN-1、组织READ及T28病例/对象授权；管理员不自动获得资格。人工来源、扫描仪编号采用SYN-前缀开发元数据，原因必填。人工扫码须等于目标玻片当前条码；文件内病例/患者/玻片/条码需再次匹配。不匹配持久隔离，不自动更正映射。

新增合成头格式SYNTHETIC_HEADER_V1：T28运输标记后为PISSCN1换行、三UUID、34字节含校验字符条码和两个大端整数尺寸。它是契约夹具，不是WSI图片，不提供伪预览。尺寸各1–4096，只解析固定头；读取最多512字节，T28对整对象重新验hash，64MiB/30秒/双worker限额继承。明确识别TIFF/BigTIFF容器magic后返回NOT_CONFIGURED，不猜厂商；SVS/NDPI/MRXS未配置、无代表性样本。未知格式UNSUPPORTED；ZIP直接拒绝，不解压或回退任意解析。

QUEUED→RUNNING（独立尝试UUID、操作者、30秒租约，最多3次）→PENDING_DIGITAL_QC/FAILED/QUARANTINED/RETRY_WAIT。暂时存储失败或过期租约可人工恢复；5×尝试数秒退避，达到3次失败。取消有原因；过期/旧代次/取消后的完成不能改变当前状态。重复完成原键返回原回执但UI必须读取当前状态。恢复和重试均显式人工操作。

同物理玻片序列CAS分配，新扫描/重扫使用独立任务ID和不同T28对象版本；previousId明确关联原任务，原因/历史不覆盖，原任务不会自动被替换。所有导入始终未发布，成功仅表示合成头及身份核验完成，数字QC仍待T30。

批量最多10项、单病例，每项独立授权/事务/幂等键，准确逐项结果；不把失败项标成功。每病例最多1000任务、分页20最多50页。业务状态与追加事件、审计同事务，读和重放重新授权；I/O不占业务事务。输入依赖变化时查询显示失效，完成重新校验。

UI从已有合成原件与物理玻片选择，明确批量结果、映射、原件hash、尝试代次、未发布原因。脏表单、取消等待、迟到响应与原键重试安全；无文件路径/URL/密钥输入。需覆盖权限、双向身份、重扫、新旧回调、并发、审计回滚、格式边界、UI及真实本地E2E。完整后端/真实E2E若受现有BOM缺失阻断单列，不据此宣称厂商兼容或可投产。
