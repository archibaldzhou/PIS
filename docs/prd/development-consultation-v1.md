# T25 院内合成会诊与复阅开发 PRD v1

2026-10-03；用户授权本地开发，非医院临床规则批准。实际查看同一环境已授权 UI-021 科内会诊与讨论；沿用其目的、参与者、确切报告/材料依据、个人意见和人工汇总布局。不实现院外共享、真实通知或诊断生成。

## 版本与授权

CONSULT / REREAD 两种明确目的类型；请求固定病例、当前草稿修订及模板、分配代次、材料/QC依赖快照，强制目的与原因。当前已领取且合格的医生发起，明确邀请1–10名本作用域合格医生（不含自己），设未来最多30天的开发有效期；此上限非医院制度。邀请不写入任何全局权限表，仅允许会诊专用API读取此病例的绑定内容。原组织范围和医生资格仍须有效，管理员无自动权限。

参与者可接受、拒绝、退回；发起侧可撤回、撤销某参与者。拒绝/撤销/到期后不能继续通过会诊API读写内容。新的当前领取人可以基于原病例权查看历史，但旧分配会诊不能继续就绪，须重新建立请求；原医生不会因曾发起获得永久访问。终止/失效保留历史。

## 人工意见与分歧

接受后可追加个人版本化意见，明确 AGREE / DISAGREE / UNKNOWN，非诊断类别。只能写自己的意见。每次基于会诊CAS；并发命令至多一个旧版本成功，冲突须读取新版本后人工重试，不能静默覆盖。

当前医生汇总绑定所有参与状态和确切最新意见ID，人工填写汇总及UNRESOLVED/RESOLVED；任何无意见或未接受者均阻止就绪。RESOLVED不自动视为一致：每位参与者必须明确确认这一汇总，确认不改写个人原意见；新意见/拒绝/撤销/资格变化使旧汇总失效。未知/分歧可保留UNRESOLVED，不计票、不自动诊断。

报告修订/模板、材料/QC、分配或资格发生变化时显示失效原因，禁止继续接受为就绪或采纳；允许撤回/撤销/退回清理。个人及汇总历史不可删除。

## 明确非签署采纳

仅当前合格ACTIVE领取人，在全部明确确认、依据仍匹配时，可人工填写“采纳追加说明”，追加到当前草稿notes并新建修订。原字段及notes正文保留，新修订引用会诊及汇总和确切意见来源；不自动复制诊断，不改模板，不触发复核/签署/发送。已模拟签署草稿不可通过采纳绕过T20。重复采纳至多一个修订；同键重试返回原回执并重新鉴权。

## 工程与验收

同申请根锁、提交时资格重读、CAS、T07幂等、事务内材料/报告版本检查和原子审计。只用合成人工文本，默认合成开关关闭。UI显示依据、原意见、人工汇总、独立确认及失效原因；切病例/请求/动作提示脏输入，迟到响应丢弃，未知提交保留原键输入。

覆盖权限/撤销/过期/跨组织、并行意见CAS、草稿/QC/转派失效、汇总重算/确认、重复采纳与审计回滚；适用单测、真实PG探针、HTTP与真实E2E源码及可执行前端回归。Maven依赖缺失时明确记录后端/真实E2E未验证，不等同可合并或投产。
