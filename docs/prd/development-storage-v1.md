# T28 私有原件存储开发 PRD v1

2026-10-03；用户授权的合成开发范围，不代表医院/临床/生产批准。已查看授权UI-042影像归档与存储实际图片。仅实现私有本地provider、不可变原件版本、权限、容量及恢复；无扫描仪、WSI解码或阅片就绪承诺。

## 对象、权限与限额

稳定asset ID与每次独立version ID；元数据绑定医院、申请、病例、用途、序号、字节数、SHA-256及provider根身份。不接受用户路径、URL、远程字体或任意文件名。只接收SYNTHETIC_ORIGINAL/application/octet-stream，流首标记PIS-SYNTHETIC-STORAGE-V1换行，仅用于人工确认的合成夹具。

默认开发开关关闭，只有dev/test合成主体可用。组织READ、独立SYN-STORAGE-1资格和显式病例范围（或all_cases开发授权）都需当前有效；写、容量独立权限。病例非RECEIVED或身份隔离阻断操作，管理员无默认权利。文件READY仅表示字节完整，非QC/临床/WSI验证。

单原件25字节至64MiB且包含合成标记；本地流并发最多2、30秒期限，固定内存块64KiB。全量下载仅限1MiB；更大对象必须单Range，单次最多1MiB，拒绝多Range/后缀Range。每主体每分钟最多60次/32MiB读取尝试预算（失败不返还）；每医院预留物理预算512MiB（暂存与原件按2倍长度计费，失败不自动释放）。所有数字均为明确合成开发限制，不是医院容量承诺。

## 双写、版本和恢复

先提交预留、配额和审计，再流式写唯一暂存文件。长度/摘要/合成标记一致才提交STAGED。完成命令以CAS把FINALIZING及持久化任务同事务提交；事务外仅CREATE_NEW创建不可变原件，校验/force完成后再提交READY及任务完成审计。任何阶段DB或文件失败都保留可追溯状态；重复完成对同一确切版本重新校验，禁止覆盖原件。部分原件不能重写，需新版本；完整原件但DB未确认时可人工对账恢复。

进程对私有root加独占锁，拒绝两个provider进程同时拥有同一root；POSIX私有权限、SecureDirectoryStream及NOFOLLOW防止路径/符号链接逃逸。原件与暂存字节不入PG。S3仅接口契约，状态NOT_CONFIGURED，无SDK、端点、密钥或外网调用。

下载/预览先鉴权，打开确切不可变版本并流式复核整件摘要，读取前预留限额并审计尝试，读取后再复核权限、提交访问审计后返回有界字节。响应仅受控UUID文件名，no-store、nosniff、octet-stream attachment。容量只显示配置root所在卷的实测total/usable及本系统预留预算，明确共享卷可用量不等于医院容量。

## 清理、UI与验证

清理仅dry run列出任务自己已登记失败版本的暂存候选，并核对根身份/状态/引用；不删除任何文件、旧原件或用户对象，未知文件不作为可删对象。所有恢复均显式人工命令，不自动临床操作。

UI展示未配置/失败/待完成/已校验、版本/哈希/真实容量；浏览器只生成确定性合成夹具，不读取真实文件。切换病例清输入、取消/迟到响应不串对象，失败重试复用原键，恢复与下载明确操作。测试覆盖真实本地文件、重启/部分写、长度/摘要、路径/符号链接、并发、配额、DB回滚及真实Spring/PG和E2E源码；缺失依赖导致未执行项单列，不把接口契约当S3集成证据。
