# T19 固定合成PDF与打印记录开发PRD V1

2026-10-03，依据用户明确T19范围，已查看授权UI-024实际图片中的固定报告版本、摘要、重试和打印记录。仅合成演练；无临床/CA/法律效力，无真实发送、打印机命令、T20更正或部署。

首次生成只针对T18的确切SIMULATE_SIGN事件和冻结修订，绑定模板code/version、字段schemaCode、复核ID、依赖摘要及完整冻结字段。创建前后复核当前资格、病例/组织作用域、原复核/模拟签署资格、分配和QC依赖；依赖不再有效时禁止新生成与打印请求。已有历史PDF允许当前有权人员访问，明确历史产物不是当前就绪证明。沿用合成dev/test默认关闭门禁、独立复核资格，不给管理员隐式权利。

每个模拟签署事件只存在一个artifact v0。纯Java固定布局，以随应用发布且哈希固定的中文字体渲染灰度页面，再写入仅含静态页面图像的PDF；不接受HTML、脚本、链接、PDF输入、用户路径或远程字体，不运行浏览器或子进程，不抓外部URL。PDF是栅格页面，不提供可搜索文本/PDF-A或电子签名。每页页眉页脚明确“合成演示／非临床报告”，显示页码、确切修订和模板；正文只来自冻结的人工字段。不能用新模板重生成旧版。

渲染上限：字段沿用T17严格模式与32000 UTF-8字节；总文本24000字符；最多16页，每页1240×1754灰度图；最终PDF最多4MiB；每进程同时最多2次渲染，5秒协作式截止检查。仅支持内置字体覆盖的字符，缺字拒绝，不静默替换。字体或编码失败拒绝生成，不存残缺产物。渲染在数据库事务外；提交短事务重新绑定冻结版本、哈希和授权，唯一约束及T07幂等/CAS保持单产物。失败无可见部分产物。

小型受限PDF以不可变bytea与元数据同库原子保存（不是大文件/WSI存储方案），SHA-256、字节数、页数、渲染器版本、字体哈希及完整绑定可追溯。已有artifact不重渲染；重复下载必须同字节，渲染器升级不替换旧产物。生产对象存储/容量批准另行处理。

预览/下载POST接口带CSRF和原键，服务端核验caseId/artifactId/version/hash，再追加独立PREVIEW或DOWNLOAD审计记录后返回相同PDF字节。无公开文件路径、用户文件名或未审计GET下载；Content-Disposition仅服务端UUID文件名，no-store和nosniff。失败/未知响应不代表未访问，重试原键不重复计数。接收浏览器动作不能证明用户已阅读或保存成功。

打印请求与自报另需当前workflow PRINT授权，重印需REPRINT，不以复核资格替代打印权限。PRINT_REQUEST仅登记人工打印意图，REPRINT_REQUEST要求已有原请求并记录同一产物和原因；不调用window.print或打印设备。USER_REPORTED_PRINTED、USER_REPORTED_FAILED、USER_REPORTED_CANCELLED仅允许原请求操作者自报一次，CAS和唯一约束阻止矛盾结果；没有硬件确认状态或“实际打印成功”。不可变追加历史按20项分页，原因必填，重印不新签署或生成PDF。

前端保护病例切换、迟到响应、取消、脏输入、双击与断网原键确认；PDF在内存校验hash/size后预览或下载，退出/切病例撤销Blob URL，无持久缓存。打印按钮仅登记意图并显示模拟边界。

验证不可变、绑定/hash、越权、幂等/并发、审计回滚、输入边界、中文换页页眉页脚与实际PDF页面、UI和真实E2E。完整Spring编译/E2E/CI若仍被依赖阻塞必须明确未验证，仅中文本地独立提交。
