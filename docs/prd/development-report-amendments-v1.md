## 范围与规则

补充 ADDENDUM 和更正 CORRECTION 分别建模，必须填写原因、确认病例及确切原模拟签署/修订、分配版本和链版本。仅当前已领取的合格医生、同病例/组织且 QC/身份门禁就绪可新建。当前冻结版仅指合成流程，不具临床或法律效力；开发合成模式默认关闭。

每次新建产生独立草稿 ID、全新不可变修订 ID 和递增的病例修订号。保留原模板及人工字段作为明确显示的初始副本；用户随后在 T17 草稿页人工编辑，不自动生成诊断。不能继承旧版有效复核或模拟签署。原冻结修订、PDF、哈希、审计不修改或删除。

病例根锁、链头 CAS、唯一原签署后继和唯一病例链序号保证单一进行中分支。旧版仍是当前冻结版，直到新草稿完成 T18 独立复核/模拟签署。未完成草稿阻止再次分支，不提供删除/撤销已创建分支接口；取消只是取消本地输入。后续保存/复核使用现有修订与依赖 CAS，资格、分配、QC 变化继续失效。

新模拟签署时同事务追加替代关系，绑定原签署、新签署、新修订及分支，并固定下游状态 PENDING_NOT_SENT；不伪造 ACK，不执行 T21 送达。新签署使用 T19 生成独立不可变 PDF；原 PDF 只读取保存字节。历史产物不得借当前新版依赖通过打印门禁。

## 界面与接口验收

新增“报告补充与更正”工作页，显示当前冻结版、当前未完成草稿、类型、原因、原版关联及分页版本链。历史详情明确只读和旧版提示，固定 PDF 预览/下载走现有审计 POST，不开放文件路径。整链及历史正文均服务端鉴权。

新建需明确确认；类型切换确认清空、取消保留；冲突保留输入、未知结果原键重试；双击单发，病例/范围切换丢弃迟到响应并处理脏状态。新建成功提示去人工草稿页编辑，然后重新复核/模拟签署/生成固定 PDF。历史查看不能悄悄切换当前草稿。
