## 范围与状态

队列以既有已接收病例的稳定 caseId 为对象，申请/患者/组织关系由服务端解析。没有分配记录时是 UNASSIGNED，版本 -1；分配生成唯一病例任务 ASSIGNED v0；指定人员领取变为 ACTIVE；未分配病例可由合格人员直接领取为 ACTIVE v0。当前 ACTIVE 持有人可转交到同范围合格人员，状态回到 ASSIGNED，受让人须显式领取。分配不能覆盖已有持有人，不提供管理员抢占、自动分配或自动临床动作。

仅 T16；不创建诊断正文、报告、签署、发布、优先级规则、会诊或 WSI/AI 就绪假数据。单项操作，无批量暗选。不存在材料就绪时仍可查看队列及阻断提示，不能分配/领取/转交。

## 合格人员与授权

新增默认不授予的 diagnosis_grant，按 userId+scopeId 记录 can_assign/can_diagnose、合成资格 SYN-DIAG-ASSIGNMENT-1、版本和有效期/撤销。必须同时满足当前启用的 synthetic_only 账号、启用范围、有效 workflow READ 与诊断授权。can_assign 仅分配，不自动允许领取；can_diagnose 允许本人领取及当前持有人转交。角色名称、客户端 actor 或管理员身份均不赋权。

目标人员必须在同一 scope 有有效 can_diagnose，锁后复核；未知/跨组织/不合格目标统一不可用。人员搜索按服务端 scope 授权且有数量上限，结果只含稳定ID与合成显示名。队列、详情、事件和数量均服务端鉴权，未授权对象与不存在同404。

## 门禁与并发

每次实际变更在同一申请根锁后重读接收状态和材料/QC。至少一张 ACTIVE 玻片，病例所有 ACTIVE 材料及来源的有效 QC 均 PASS，身份隔离即使材料已作废也不能借转交绕过；未评估、失效、隔离和未知就绪均阻断。资格、授权期限和账号状态也在锁后复核。已发生分配保留历史，QC后来撤销则禁止下一步，不自动解除或转交。

T07 独立短事务：授权共享锁→申请 FOR UPDATE→病例任务CAS；expectedVersion和confirmedCaseId必填，分配/转交targetUserId必填，领取目标必须为空，reason必填。唯一病例任务抵抗并发首次分配；并发领取/转交仅一个版本胜出。任务、追加事件、审计和幂等回执同事务；失败完整回滚。重放重新鉴权后返回原回执，不把历史回执当成当前就绪；异参拒绝。客户端保留原输入和键处理未知结果，不乐观成功。
