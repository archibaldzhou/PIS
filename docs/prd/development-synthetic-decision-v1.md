# T37 医生人工处理合成结果与报告引用 PRD v1

用户授权合成开发；已在原环境查看授权 UI-046「AI人工复核与采纳」实际 PNG：左侧人工处理/理由，右侧不可变来源与目标版本，提交前预览和明确确认。原型不是临床批准。本实现只处理整个不可变合成结果，不把示意ROI或强度解释为临床建议。

仅当前已领取病例且具有效诊断资格的医生，兼具既有结果资源权限，才能读取及提交。沿用T16报告所有权、QC、身份/组织门禁及T35默认关闭开发模式；管理员无临床权限。结果所有者限制不扩大成共享权限。

医生显式选 ACCEPT_REFERENCE / REJECT / DEFER，填写1–500字原因并确认目标病例、结果与报告修订。每次记录固定result ID、完整T36 binding、artifact hash、目标revision/模板/分配版本、actor/time。每病例/结果CAS版本；结果和报告最新修订在持有病例锁的命令事务内重新校验。拒绝/暂缓不修改草稿；采纳仅新建内容完全相同的草稿修订并关联不可变非诊断引用，绝不把结果强度写入诊断字段，不签署、不自动采纳。旧修订/意见不覆盖；已模拟签署的当前报告拒绝全部新操作。

幂等沿用T07；同键异参冲突。重放核验当前资格及结果，但返回原回执，不重复草稿/记录/审计；另一个key的陈旧CAS冲突。重复采纳在未有新决定前拒绝。理由/内容不会进入普通日志。审计失败回滚草稿、记录、版本头、幂等记录。

历史按授权病例/结果分页，每页20、最大100页；展示精确当时快照、采纳修订与当前结果有效/失效状态、当前报告是否仍指向该修订。源QC/模型撤销立即阻止新决定，保留可授权历史。没有T38的全链失效广播；不自动更正历史报告。后续草稿编辑不自动继承新采纳动作，引用按确切采纳修订追溯。

UI从报告编辑器进入独立人工处理面板。脏表单进入/离开需确认；处理中禁止切换和双击；不确定结果保留原键/原输入用于确认。取消等待不能假装服务端撤销；卸载和切病例丢弃迟到响应。显示已确认版本，动作提交有明确确认；错误/冲突不静默重写表单。

验证含权限、过期/撤销、跨病例、冻结草稿、CAS、重复/异参、真实HTTP、审计回滚、历史不可变、UI取消/重试/迟到/截图以及真实服务E2E。临床executionAllowed=false始终保留。不推理/安装模型、不用真实患者、不外发、不部署。后端本地依赖阻塞须如实报告，完整CI由父会话确认；validation/t37通过前不合main。
