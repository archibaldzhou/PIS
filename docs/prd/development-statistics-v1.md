# T27 工作量、TAT、QC 合成统计 PRD v1

2026-10-03；用户明确授权的开发规格，非医院指标/SLA批准。已实际查看授权UI-028质量看板、UI-031统计查询与授权导出。原型没有独立确认CSV需求，当前不导出、不投递。

## 固定口径 SYN-STATS-1

按一个授权组织、选定IANA时区的起止日期（两端业务日包含，转换成[start,end) UTC），最大92天，截止时间由服务器冻结。计时为自然秒，不扣节假日、暂停或非工作时间。无SLA/超时阈值。

- 接收TAT：以申请第一次提交事件所属日入组，第一次RECEIVE事件结束。一申请计一次；编辑、幂等重放和重新提交不增加分母。完成数/有效完成时长样本数分别展示；退回列EXCLUDED并保留退回事件；其余尚未接收列为OPEN，等待截止时长独立显示，不混入完成中位数。
- 技术工作量/TAT：独立任务第一次CREATE事件入组，第一次FINISH_SIMULATION结束；独立返工任务有新ID独立计数，重复完成/重放不重复。ABORT任务单列EXCLUDED而非完成；不把“人工模拟完成”视为仪器完成。
- 报告TAT：病例第一次接收入组，第一次SIMULATE_SIGN结束；后续修订/补充/更正不再计首次完成，均明确合成模拟、无临床签署效力。缺少起点但有期内终点列UNKNOWN，不补零。
- QC：材料首次CREATE/ORIGINAL事件入组，按截止前最新质量事件及其确切assessment解释；PASS/FAIL/IDENTITY_MISMATCH为有效评估分母，后两者为不合格分子；PENDING、未评估、撤销、返工、失效、材料作废或来源不再就绪单列UNKNOWN/EXCLUDED，不能把登记或空结果当阴性/通过。QC比率分母0显示无数据，不显示0%。
- 每条详情保存实体/申请ID、源起止事件ID及时间、状态和自然秒；不存姓名、患者ID、正文、自由文本或操作者姓名。工作量来自实体去重后的完成数，不统计审计读取、修改次数、幂等回执或消息重复次数。

## 权限与一致性

独立SYN-STATS-1统计资格，组织READ授权同时有效；统计资源可限定具体申请，或显式授予该组织全部申请，默认不授予。接收/技术/QC仍需原域权限；报告时间统计需独立can_report，不授予报告正文、编辑或签署权。小样本无额外跨范围聚合，每项先授权再聚合；下钻需can_drill。管理角色不默认获取统计权限。

一次只读业务查询创建不可变派生快照，不改变业务/临床状态。来源查询单SQL同一MVCC视图，最多5000事实行，超限拒绝而非截断。快照绑定创建者、组织、口径、时间区间和截止时刻；每次访问重新验证所有受限行的当前权限，撤权后拒绝整个旧快照，不能通过旧总数/明细继续读取。快照主体、事实行不可更新删除，精确摘要防误绑定。

页面采用显式查询，筛选草稿与已应用快照分离，取消/新筛选丢弃迟到响应；查询重试保持原键。明细20条/页、页号1–250、稳定排序枚举。SQL时限5秒、事务10秒。空范围显示“无数据”，有样本但完成0是真实零；无权限和查询失败单独展示。只记录最小审计ID/操作码。

## 验收及限制

覆盖冻结时钟、DST和日期边界、缺失/逆序时间、重复/修订/作废、部分授权、撤权、快照不可变和并发源变化、总数明细一致、迟到/取消/筛选切换/失败重试。新增真实Spring/PG和本地E2E源码；缺失BOM的完整后端/真实E2E及CI边界如实登记。不处理真实患者、外发、实际签署或部署；合成开关默认关闭。
