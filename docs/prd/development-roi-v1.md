# T32 合成ROI、像素测量与双视图开发PRD v1

2026-10-03；用户授权开发，当前实现者负责交付。已检查合法UI-041多片对照与标注实际图片，沿用T31真实OSD和合成PNG；不采纳原型中的临床建议或物理校准值。

图像像素为规范坐标：点1顶点、矩形2对角点、多边形3–32顶点，最多50个稳定ROI ID、每ROI最多100修订；边界含图像边缘，拒绝非有限数、自交、重复点、零面积、越界。编辑明确提交，无自动保存。矩形、多边形和点在真实OSD上点击创建，选择后顶点重定位编辑；本地撤销/取消不改变服务器历史。

V30新增扫描级标注集合CAS及不可变修订，精确绑定manifest hash、源扫描版本/对象/hash。写入采用当前T30资格/病例/组织范围和作者权限、CSRF、幂等及原子审计，软删除保留作者/原因/历史。重扫另起集合，绝不自动搬运。当前读取/编辑必须仍发布；QC撤销后只允许具备明确原病例/资源权限与专业资格的用户显式查看历史，不返回瓦片、不授予编辑。历史读取独立审计，无自动回退。

MPP是独立不可变版本，X/Y分别为um/px。默认未知，只显示像素长度/面积。开发仅允许明确SYNTHETIC_TEST校准记录，强制人工来源和原因，有界正数；显示合成µm/µm²且不宣称临床准确性。测量结果绑定校准版本；不能以屏幕缩放代替MPP。

视图变换支持旋转、水平翻转、平移、缩放和显式图像矩形裁剪；几何保存前经OSD窗口→图像逆变换，显示用正变换，裁剪仅限制可见/输入区域不改写原始坐标。数值模块使用可逆仿射变换并测试往返，图像叠加使用OSD同一变换。

双视图独立扫描ID/请求/实例/状态，默认不同步。仅同一确切manifest允许用户显式启用像素恒等映射同步；不同版本或扫描无批准映射则同步不可用，不自动配准。切图、关闭、撤权取消请求并清理画布/标注，不共享敏感缓存；迟到保存只能影响其原对象，不能回填新对象。切换带未保存编辑需明确放弃确认，结果未确认时保留原键重试。

验收含真实画布点击/编辑/截图像素检查、数值性质与边界、权限/CAS/幂等/审计回滚、软删除/历史、撤销、配额、取消/重试/双视图切换。合成模式默认关闭，无真实患者、AI、设备、CA或部署。完整后端/E2E若仍缺BOM则诚实列阻塞，独立validation/t32待父会话CI，未通过不合main。
