# T34 AI注册与适用契约开发PRD v1

用户授权合成开发，当前实现者负责工程验证；无医院/监管/临床批准。实际查看已授权UI-043。仅实现注册与适用性契约，不下载模型、不推理、不训练、不访问外部服务。

注册采用范围内模型系列CAS与不可变版本：UUID、digest、预处理版本、固定配置schema、支持输入、病理类型、染色、扫描仪/版本、质量和校准要求、合成批准范围、验证证据状态及限制。状态DRAFT/VALIDATION_ONLY/DISABLED/RETIRED，启用验证权限独立于注册；管理员无默认资格，临床批准和执行权限始终不存在。

T29未提供可信病理类型/染色/扫描仪软件版本，因此追加显式人工合成适用资料版本，不从文件名或空值猜测。资料绑定当前发布扫描、原件和hash，含UNKNOWN；校准来自T32确切版本，只接受合成校准或明确PIXEL_ONLY。模型适用判定在服务端重新检查当前病例/组织/医院、身份、QC、扫描版本、资料版本、模型头/状态版本及校准；返回VALIDATION_ONLY_APPLICABLE/NEEDS_REVIEW/NOT_APPLICABLE，任何结果executionAllowed=false，非任务许可。

模型元数据新版本不覆盖旧版；状态变更CAS并追加历史。资料登记、状态、注册及判定都幂等、事务内审计，撤销/退休/模型换版/QC或资料变化使旧判定不可重放成当前许可。权限锁与模型锁参与同事务，未来T35必须重新调用当前判定，不能消费旧响应。

UI在病例扫描上下文展示范围内模型版本、限制/缺失证据、确切依据、人工资料和判定；切换/迟到/错误/脏表单/未知写结果保持原键，不伪造许可。补后端权限/CAS/审计/撤销测试、真实E2E及UI；本地缺BOM明确标记。开发默认关闭，只合成数据；临床AI性能、监管审查、真实模型及厂商输入均未验证。validation/t34独立中文提交并普通推送，完整CI前不合main。
