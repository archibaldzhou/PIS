- V6 添加独立 RECEIVE/EXCEPTION 权限，默认 false；保留开发开关、合成账号、作用域锁、当前授权检查，未授予已有角色新权限。
- `GET /api/receptions/{requestId}`：同申请 READ 范围，返回申请身份、容器、病理号及最近100条追加事件；完整历史仍存库。
- `POST .../receive`：expectedVersion、患者 UUID、精确就诊号及逐个容器 UUID。身份/容器集合不符原子转 EXCEPTION；成功才建立病例/编号、病例范围及全部容器关联。
- `POST .../exception`：类别 IDENTITY/QUANTITY/INFORMATION 和事实原因；`.../resolve` 仅 INFORMATION 且必填补充说明，锁就诊防重复恢复提交；`.../return` 必填退回原因。均校验状态/版本、同事务事件/审计/幂等回执。
- 返回命令回执不表示“已经接收”，UI 重新读取服务器状态；未知结果保留原 key/输入，锁定表单并阻止普通导航。历史不覆盖，病例创建不授予 CASE_READ/CASE_EDIT。
- 按已实际查看的 UI-004/005 实现身份条、核对表单、计划容器、异常处理和轨迹；合成模式持续明示。不实现扫码硬件、实物交接、临床身份纠正或有条件接收。
