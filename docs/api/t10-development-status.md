## 范围与契约

- 先实际查看 UI-007；[开发规格](../prd/development-labels-v1.md)只覆盖已接收容器。独立PRINT/REPRINT，默认false；沿用默认关闭、dev/test、合成账号、当前作用域授权和CSRF。
- `GET /api/labels/containers/{id}` 返回授权容器版本及最近100任务，`GET /api/labels/jobs/{id}` 返回冻结快照及最近100事件。无权限/不存在隐藏为404（申请不可见沿用 REQUEST_NOT_FOUND），未授权不暴露患者或条码。
- `POST /api/labels/containers/{id}/jobs`：申请/容器版本，生成一次独立条码身份及根任务；已有根任务要求重打。
- `POST /api/labels/jobs/{id}/{reprint|simulate-failure|retry|cancel}`：expectedVersion、必填原因、Idempotency-Key；重打新建关联任务并推进父版本，其余推进原任务版本。失败重试不换任务/实体/条码。取消为原任务终态，新重打是明确新意图。
- `POST .../verify`：确切容器ID与完整Code39/Mod43条码；验证格式、校验位、任务条码及容器一致，错误409，不隐式查找并切换其他患者。
- V7追加稳定标签身份、冻结任务快照、追加事件及复合关系约束；不改V1–V6。关键写入/事件/审计/幂等原子一致。没有真实设备适配器、外部回调或“已打印”状态。
- 预览/浏览器对话框由用户点击触发，打印前重新鉴权并核对任务版本/状态；关闭预览或对话框不记录物理打印成功。内容不存localStorage，不使用外部条码生成服务。
- 未新增运行时依赖；Code39受限编码决策与映射来源许可见[ADR](../adr/0002-synthetic-label-barcode.md)及仓库third-party目录。
