# T27 合成统计接口与交付记录

版本 SYN-STATS-1。开发合成模式仍默认关闭。只读业务事件；创建的是不可变派生统计快照，不改变申请、材料、报告或临床状态。未实现 CSV/外发。

- `POST /api/requests/statistics/scopes/{scopeId}`：`{from,to,zone}`，日期包含首尾业务日，命名 IANA 时区，最多92天。CSRF和幂等键必需。同键同参返回同一快照，重试仍复核当前权限。
- `GET /api/requests/statistics/scopes/{scopeId}/{id}`：固定汇总；仅创建者可读，当前组织READ和独立统计资格有效。`metric=RECEPTION|TECHNICAL|REPORT|QC`用于明细，另需can_drill及对应指标权限。`sort=ENTITY|START_ASC|START_DESC`；`page=1..250`，每页20条。
- 上限5000事实行，超限拒绝不截断；每主体最多500个合成快照；事务10秒、SQL5秒。没有后台导出、外部收件人、医院SLA或工作时长日历。
- 快照包括口径版本、组织、筛选、截止时刻、事实摘要。事实包含实体/申请和确切起止事件ID、UTC时间及状态；没有姓名、患者ID、正文或自由文本。计时自然秒。退回申请单列EXCLUDED并绑定退回事件。OPEN是截止时等待，不计入完成中位数；缺失/逆序为UNKNOWN，真实零与无有效分母分别返回0/null。
- QC分子是有效FAIL（含身份不符），分母PASS+FAIL；撤销、待定、来源隔离/失效单列UNKNOWN，作废单列EXCLUDED。当前查询的单SQL MVCC视图冻结事件与依赖状态，不提供任意历史时刻回算；旧快照保留原来观察的事实。
- 所有聚合前应用组织及申请授权。撤权/到期或指标权限改变时，旧快照总数、明细和重放均拒绝，不返回局部残留。没有全局小样本聚合或跨授权范围推断。
- 生成与幂等回执、审计同事务；读取和下钻也审计。`STATISTICS_NOT_FOUND`统一隐藏对象/权限差异；日期、范围、数量和完整性失败有独立业务码。日志不输出统计事实内容。
